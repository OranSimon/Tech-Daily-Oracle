## 6. Papers & Research Frontiers

### FAPO: Fully Autonomous Prompt Optimization of Multi-Step LLM Pipelines
- **Authors / Lab:** Paul Kassianik et al. / 机构未知（Claude Code 为核心工具）
- **Source:** Hugging Face Daily Papers / arXiv 2606.19605
- **核心贡献:** 以 Claude Code 为自主 Agent，对多步 LLM Pipeline 进行闭环诊断-提案-验证的全自动提示优化，率先从单步扩展到多步系统。
- **技术意义:** 对构建生产级 RAG 和 multi-agent 系统的工程师具有直接参考价值；先做 prompt-only 修改，再升级到代码层，体现务实的渐进优化路径。
- **Code/Demo:** pending（未见仓库）
- **信号强度:** medium

### iOSWorld: A Benchmark for Personally Intelligent Phone Agents
- **Authors / Lab:** Lawrence Keunho Jang et al. / Carnegie Mellon University（Salakhutdinov）
- **Source:** Hugging Face Daily Papers / arXiv 2606.09764
- **核心贡献:** 首个在原生 iOS 模拟器上引入持久用户身份的 mobile agent benchmark，覆盖 26 个专建 iOS 应用，跨 app 关联交易记录、消息等个人化上下文。
- **技术意义:** 直接对标 Apple Intelligence 落地需求；为 on-device 个人 AI Agent 提供首个带用户身份的评估框架，工业转化价值强。
- **Code/Demo:** 未确认
- **信号强度:** strong

### UFP4: Rethinking Shrinkage Bias in LLM FP4 Pretraining
- **Authors / Lab:** Qian Zhao et al. / 机构未知
- **Source:** Hugging Face Daily Papers / arXiv 2606.20381
- **核心贡献:** 识别 E2M1 FP4 格式中因几何不对称导致的系统性 Shrinkage Bias，提出 UFP4 修正配方，直接针对 Nvidia Blackwell/Rubin 和 AMD MI350 硬件路径。
- **技术意义:** 工程落地价值高；FP4 训练成为主流硬件路径之际，消除系统性数值误差对 LLM 质量的隐性损害具有实际意义。代码尚未开放，独立验证待见。
- **Code/Demo:** pending
- **信号强度:** medium

### ENPIRE: Agentic Robot Policy Self-Improvement in the Real World
- **Authors / Lab:** Wenli Xiao, Jia Xie et al. / UC Berkeley, NVIDIA, UT Austin（Goldberg, Jim Fan, Yuke Zhu）
- **Source:** Hugging Face Daily Papers / arXiv 2606.19980
- **核心贡献:** 将 coding agent 自动化能力首次延伸到真实物理世界机器人策略迭代中，实现环境重置-执行-评估-算法改进的全闭环，无需人工监督。
- **技术意义:** 若验证成功，可将 embodied AI 研发周期从数周压缩至数小时——是物理智能领域的潜在里程碑。作者阵容顶尖。Abstract 截断，实验范围和泛化性尚待代码和完整论文验证。
- **Code/Demo:** pending
- **信号强度:** strong
