## 6. Papers & Research Frontiers

### NVIDIA Cosmos-H-Dreams: Real-Time Generative Physics Simulation for Surgical Robotics
- **Authors / Lab:** Javier Gamazo Tejero 等 / NVIDIA
- **Source:** arXiv (cs.RO)
- **核心贡献:** 提出实时手术世界模型，用 action-conditioned 生成 + teacher-to-student 蒸馏实现照片级软组织变形仿真。
- **技术意义:** 若验证有效，可大幅减少手术机器人训练对动物/尸体实验的依赖，为手术 AI 提供规模化合成数据；商业与伦理价值都很大。
- **Code/Demo:** 无
- **信号强度:** strong（但 hype 风险 medium，无代码无实验细节）

### Meta^n: Recursive Self-Improvement through Emergent Depth
- **Authors / Lab:** Zae Myung Kim 等
- **Source:** arXiv
- **核心贡献:** 固定单一 meta-operation、递归作用于自身输出，突破此前自我改进系统约两层的 meta 深度上限。
- **技术意义:** 为 LLM agent 的自我修正与长程推理提供更深层递归框架，是 RSI 方向的重要理论推进；但无实验验证，落地存疑。
- **Code/Demo:** 无
- **信号强度:** medium

### StarHarness: Evolving Harnesses with Stratified Search for Enterprise Environments
- **Authors / Lab:** Esakkivel Esakkiraja 等
- **Source:** arXiv cs.AI
- **核心贡献:** 固定模型权重、用分层搜索进化"环境专属 harness"（prompt、工具接口、MCP、子 agent 结构、agent-loop 配置）。
- **技术意义:** "只进化 harness、不碰权重"的范式对部署方极有吸引力，可能成为 agent 工程化的新基线；分层任务分离（proposer-visible vs proposer-hidden）是方法论亮点。
- **Code/Demo:** 无
- **信号强度:** strong（企业场景指向明确）

### Recuris: Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses
- **Authors / Lab:** Zhaochen Yu 等（Meta/Anthropic/Alibaba 关联）
- **Source:** arXiv / Hugging Face Daily
- **核心贡献:** 用工作记忆跟踪任务进度、从经验记忆引导技能选择，把执行过程转变为结构化证据以定位失败。
- **技术意义:** 直击长程 agent 的记忆漂移与技能错配问题；与 Meta^n、StarHarness 同日出现，说明"harness + 记忆 + 递归"正在成为 agent 研究的主线。
- **Code/Demo:** 无
- **信号强度:** strong
