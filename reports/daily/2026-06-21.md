## 6. Papers & Research Frontiers

### FAPO: Fully Autonomous Prompt Optimization of Multi-Step LLM Pipelines
- **Authors / Lab:** Paul Kassianik, Baturay Saglam, Huaibo Zhao et al. / Anthropic 关联
- **Source:** arXiv 2606.19605 / Hugging Face Daily Papers
- **核心贡献:** 提出完全自主的 LLM 流水线提示优化框架，使用 Claude Code 作为优化 Agent，自动诊断中间步骤失败并迭代修复，无需人工提示工程。
- **技术意义:** 对 LLM 流水线工程师有直接实用价值，将 pipeline 调优从手动变为自动化 Agent 任务；同时作为 Claude Code Agentic 能力的真实压测。
- **Code/Demo:** 无（链接至 HF papers）
- **信号强度:** strong

### ENPIRE: Agentic Robot Policy Self-Improvement in the Real World
- **Authors / Lab:** Wenli Xiao, Ken Goldberg, Linxi "Jim" Fan, Yuke Zhu 等 / UC Berkeley · NVIDIA · UT Austin
- **Source:** arXiv 2606.19980 / Hugging Face Daily Papers
- **核心贡献:** 提出真实世界中机器人策略闭环自我改进框架，结合 coding agent 与自动化重置/评估反馈，消除人工监督瓶颈。
- **技术意义:** 首个在真实物理环境中实现机器人策略自主迭代的完整系统，对迈向通用物理智能具有里程碑意义；Ken Goldberg + Jim Fan 的作者阵容大幅提升可信度。
- **Code/Demo:** 无（摘要被截断，方法细节待确认）
- **信号强度:** strong

### iOSWorld: A Benchmark for Personally Intelligent Phone Agents
- **Authors / Lab:** Lawrence Keunho Jang 等 / Carnegie Mellon University（Salakhutdinov 团队）
- **Source:** arXiv 2606.09764 / Hugging Face Daily Papers
- **核心贡献:** 首个在 iOS 原生模拟器中引入持久用户身份（交易记录、消息历史、偏好）的个性化手机 Agent 基准，覆盖 26 个原生应用。
- **技术意义:** 填补现有 mobile agent benchmark 缺乏用户个性化维度的空白，直接服务于 Apple Intelligence、Gemini on-device 等产品评测需求。
- **Code/Demo:** 无（待确认）
- **信号强度:** medium

### The FID Lottery: Quantifying Hidden Randomness in Generative-Model Evaluation
- **Authors / Lab:** Nicolas Dufour, Alexei Efros, Patrick Pérez / UC Berkeley · Valeo AI
- **Source:** arXiv 2606.20536 / Hugging Face Daily Papers
- **核心贡献:** 系统量化 FID 指标在训练与采样两个随机性维度上的方差，通过数百个 SiT 模型实验证明单点 FID 汇报存在系统性可复现性失效。
- **技术意义:** 直接挑战图像生成 AI 排行榜的可信度，可能推动整个领域评估规范改革；Efros 参与赋予该结论较高学术权威性。
- **Code/Demo:** 无
- **信号强度:** strong

## 9. China Tech

### 华为昇腾生态结构性确立

**技术进展与产品发布**
ByteDance 重启与华为的昇腾 950 采购谈判；Alibaba Cloud 同日部署 DeepSeek V4 并启动昇腾采购；Tencent Cloud 加入采购竞争。三家公司同时转向，标志着中国云计算基础设施的硬件采购重心已完成从 Nvidia 到华为的历史性切换。华为 2026 年目标向 75 万台昇腾 950PR 交付（大规模量产从 4 月开始，下半年全力扩产）。

**与全球技术路线的差异**
中国云厂商现在是以国产芯片为第一选择，而非备用方案——这是自 2020 年以来第一次。DeepSeek V4 专为昇腾优化的架构决策代表了一种"随约束共演化"的战略：在可用硬件限制下优化模型架构，而非等待硬件追赶西方水平。这条路径如果持续，意味着中美 AI 能力差距将不再是由单一芯片性能决定，而是取决于软硬件协同整合的速度。

**供应链约束**
华为昇腾的最大风险依然是 SMIC 制程瓶颈。75 万台出货目标可能在生产端受限。同时，美国正在加大对 ASML 向中国出口审查力度，进一步收紧 SMIC 先进制程的设备获取通道。

**政策影响**
美国商务部出口管制全球化（封堵海外子公司绕道路径）将短期内进一步加速国内替代，但同时也为华为 SMIC 产能扩张提供了独特窗口期。CSIS 已警告华政策制定者：中国 AI 芯片进展被严重低估，昇腾 910C 已达 H100 推理性能约 60%。

**具身 AI**
中国以 200 万台工厂机器人的全球最大部署规模主导具身 AI，宇树机器人（Unitree）在 AW 2026 首次集体亮相海外市场；中国工信部/国资委推进万台机器人国家级部署。
