## 6. Papers & Research Frontiers

### Self-Evolving Coding Agents
- **Authors / Lab:** Hao Zhou 等（事件标注含 OpenAI 关联）
- **Source:** arXiv 2608.03392 / Hugging Face Daily Papers
- **核心贡献:** 提出编码代理应具有自我演化能力——从代码库演化、依赖变化、测试失败与修复尝试中积累可复用经验，而非部署后保持静态。
- **技术意义:** 直接呼应今日 Claude Code auto mode 的产品方向：若代理能跨会话积累调试经验，“默认自主”才真正可持续。这是 Research → Product 的最短逻辑路径之一。
- **Code/Demo:** 未披露
- **信号强度:** strong

### AgentOPSD: Recursive Self-Distillation for Agentic Reinforcement Learning
- **Authors / Lab:** Zi-Han Wang 等（Alibaba）
- **Source:** arXiv 2608.05987
- **核心贡献:** 提出无需 critic 的递归自蒸馏方法，对长程多轮 agentic RL 任务做 turn 级信用分配。
- **技术意义:** 长时程任务的信用分配是代理训练的核心瓶颈；若与 RST 等合成数据方法结合，可显著降低 agent 训练成本——与 Alibaba 今日多篇 agentic RL 论文形成合力。
- **Code/Demo:** 未披露
- **信号强度:** medium

### Recursive Synthesis for Long-Horizon Terminal Tasks (RST)
- **Authors / Lab:** Zhongzhi Li 等（事件标注含 Alibaba / DeepSeek 关联）
- **Source:** arXiv 2608.05466
- **核心贡献:** 递归验证合成框架，自动生成“指令-环境-参考解-验证器”四者一致的长时程终端任务数据，解决人工标注成本高与直接生成不一致的问题。
- **技术意义:** 若成立，agent 训练数据的单位成本可下降一个数量级——这正是中国路线“效率优先”在数据环节的体现。
- **Code/Demo:** 未披露
- **信号强度:** medium

### PIMiner: Agent Against Agent — Automatic Prompt Injection Red Teaming
- **Authors / Lab:** Yanting Wang 等
- **Source:** arXiv 2608.05108
- **核心贡献:** 提出基于 agent 的自动提示注入红队系统，用“代理对抗代理”提升跨目标 LLM 的泛化性。
- **技术意义:** 在 Claude Code 默认 auto mode + 跨会话消息的今天，提示注入不是理论风险而是生产风险；此类工具是安全团队的前置防线。
- **Code/Demo:** 未披露
- **信号强度:** medium
