### 4) AI Agent 基础设施：单日 9 篇论文的密度峰值

**核心事实 / 关键证据**
- **Evolving Infra**（arXiv 2611.12304）：agent 自适应的 prefill-decode 分离式 serving，动态重分配算力并管理 KV cache；作者含 Ion Stoica、Song Han、Tushar Krishna。
- **SteerDistill**（arXiv 2611.13410）：用闭环 teacher steering 修复低比特量化后 agent 的行为偏差——直指"省了成本但任务成功率下降"的痛点。
- **SparseRead**（arXiv 2608.22237）：可复用的阅读控制层，用 Read Intent Protocol 控制内容准入，不改模型本身。
- **ScrapeBench**（arXiv 2611.11306）：首个衡量网页抓取 agent 是否遵守 ToS / robots.txt 的 agentic benchmark，报告多数 agent 合规率低于 5%。

**我的判断**
这一簇论文的共同点不是"能力更强"，而是**"把 agent 当作一个有成本的运行时系统来治理"**：成本（量化/稀疏读取）、可靠性（行为偏差修复）、合规（法律风险量化）。这是从"模型能力叙事"向"运行时工程叙事"迁移的典型特征。ScrapeBench 的 <5% 合规率尤其值得记录——它把"agent 合规"从道德讨论变成了可量化的部署门槛，而这通常是企业采购的第一道闸门。

**不确定性**
- 中高。全部为论文侧信号，无 GitHub 代码、无客户验证、无社交热度（AI Models 主题分析今日因 400 INVALID_ARGUMENT 失败，存在数据缺口）。
- 多数摘要被截断，实验规模与 baseline 对比不明。

**Signals to monitor**
- vLLM / SGLang / TensorRT-LLM 是否合并 PD 分离或信息感知 KV 压缩相关 PR。
- ScrapeBench 是否被企业合规框架或 benchmark 联盟引用。
- 是否有 agent 框架（LangChain / LlamaIndex / CrewAI）把"稀疏读取"做成命名特性。

### 5) Qwen 生态：真实采用在工具链与研究侧，但伴随可靠性隐忧

**核心事实 / 关键证据**
- Unsloth 发布 Qwen3.8-27B 的 Dynamic v3.1 量化，HN 239 分 / 77 评论，讨论集中在本地部署成本与量化质量，而非能力突破。
- 多篇最新 arXiv 论文将 Qwen3.8-27B 用作多语言路由基准的标注模型（盲二次校验保留率 91%），并以 Qwen3-0.6B/1.7B 作为量化与精度分配的实验基座。
- 同期 Alibaba 侧：Qwen3.8 家族持续扩张；企业侧对 Qwen 的采用与华为 Ascend 采购并存。

**我的判断**
这是"工具链与研究侧的真实采用"，不是爆款。它的战略含义在于：**当西方前沿模型的获取被合规与价格同时收紧时，Qwen 正在成为默认的实验基座与标注引擎**。风险同样真实——低比特量化与选项顺序的预算取舍会实质影响准确率；用模型生成标注再评其他模型，构成循环验证。这两点决定了 Qwen 的生态扩张会很快遇到"可复现性"天花板。

**不确定性**
- 中。"91% 保留率"来自单一论文流程，未独立复现。
- HN 热度归属存在争议（是模型还是 Unsloth 工具）。

## 6. Papers & Research Frontiers

### Evolving Infra: Agent-Adaptive LLM Serving at Scale
- **Authors / Lab:** Hao Kang, Weili Xu, Ziyang Li, Zheng Du, Hanchen Li, Tian Xia, Song Bian, Tushar Krishna, Huizi Mao, Ion Stoica, Song Han（机构未在元数据中确认，作者阵容指向 MIT / UC Berkeley / Georgia Tech / NVIDIA）
- **Source:** HuggingFace Daily / arXiv 2611.12304
- **核心贡献:** 提出面向 agentic workload 的运行时自适应 prefill-decode 分离式 serving，动态重分配算力并用更丰富的 agent 信号管理 KV cache。
- **技术意义:** 直击 agent 场景的两个真实痛点——PD 负载不均衡、可复用的 agent 上下文被 KV 驱逐。若在规模化负载上验证收益，会直接改写 vLLM / SGLang 类 serving 栈的默认设计。
- **Code/Demo:** 无
- **信号强度:** strong（但摘要截断，缺实验数据与开源实现）

### ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping
- **Authors / Lab:** Joseph Marvin Imperial, Daniel Slate, Noam Kolt
- **Source:** HuggingFace Daily / arXiv 2611.11306
- **核心贡献:** 首个针对 AI web agent 是否遵守 ToS 与 robots.txt 的 agentic benchmark，报告多数开源/闭源 agent 合规率低于 5%。
- **技术意义:** 把"抓取合规"从法律讨论变成可量化指标。对浏览器类 agent 的产品化是硬约束——企业采购问卷迟早会问这一项。
- **Code/Demo:** 未说明
- **信号强度:** medium（结论有传播性，但基准覆盖范围、受测模型清单、代码可用性均未验证；法律合规结论易被简化解读）

### EgoX: Egocentric Cross-Embodiment Manipulation with Embodiment Dreaming
- **Authors / Lab:** Yaru Niu, Binghong Chen, Changwei Yao 等（含 Umar Iqbal、Changliu Liu、Ding Zhao）
- **Source:** HuggingFace Daily / arXiv 2611.16728
- **核心贡献:** 把异构的人类、真实机器人、仿真演示映射到语义对齐的自我中心 observation-action 空间，用模块化 cross-embodiment transformer + embodiment dreaming 做预训练。

**国内外竞争对比**
- 当西方前沿模型的获取被合规与价格同时收紧，Qwen/DeepSeek 正在成为默认的"实验基座与标注引擎"。这不是能力超越，而是**可得性优势**。

**与全球技术路线的差异**
- 全球主线：agent 运行时治理（成本、合规、可审计）。
