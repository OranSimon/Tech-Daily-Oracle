## 6. Papers & Research Frontiers

### StateM: Reaching 95.3% Raw Accuracy, or a $15 Frontier Run, on Terminal-Bench 2.1 via Harness Scaling
- **Authors / Lab:** Ziheng Qin, Yaxin Lu, Zhangyang Atlas Wang, Kai Wang
- **Source:** Hugging Face Daily Papers
- **核心贡献:** 不修改模型权重，仅通过"harness scaling"（持久状态、阶段局部上下文、可恢复 runbook）将 Terminal-Bench 2.1 原始准确率推至 95.3%，单次运行成本 $15。
- **技术意义:** 指向"系统层优化正在取代模型层升级"的工程方向——对预算有限的企业 Agent 部署是重大利好；但也需警惕单一基准 + 未公开代码的验证风险。
- **Code/Demo:** 论文称伴随开源实现，但链接未确认
- **信号强度:** strong

### Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements
- **Authors / Lab:** Zhi Zheng, Rongsheng Chen, Yunpeng Ba, Zhenkun Wang, Yee Whye Teh, Wee Sun Lee
- **Source:** Hugging Face Daily Papers
- **核心贡献:** 论证 Evolution Strategies（ES）在长时程 Agent 微调中优于 RL——规避反向传播的高 GPU 门槛与稀疏奖励下的 credit assignment 难题。
- **技术意义:** 若成立，将显著降低 Agent 训练的算力门槛，使中小团队也能微调长程 Agent；是"去 RL 化"的 Agent 训练路线。
- **Code/Demo:** 待确认
- **信号强度:** strong
