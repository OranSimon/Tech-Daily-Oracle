## 3. Top Developments

### 1) Meta 创设无投票权 C 类股 + capex 上调至 $135–145B：AI 资本开支进入"金融工程"阶段

- **核心事实 / 关键证据**：Meta 建立新的无投票权股票类别（Class C），明确用于为 AI 支出融资、潜在并购与员工薪酬；2026 capex 指引上调至 1350–1450 亿美元；Q3 因 98.9 亿美元儿童安全和解计提，若剔除该项营业利润为 228.9 亿美元；Q4 营收指引 730–760 亿美元（市场预期约 735.7 亿）；另面临新墨西哥州 250 亿美元判罚。Muse AI 助手用户超 1000 万，购物是主要场景之一，但因分享链接泄露私人对话已暂停该功能。
- **我的判断**：这是本轮 AI 周期里第一次出现**用股权结构创新为 capex 融资**的 Mega-cap 案例。含义有三层：(1) 即便现金流最强的广告公司也认为经营性现金流不足以覆盖 AI 资本开支节奏；(2) 无投票权股本质是"融资但不稀释控制权"，Zuckerberg 的控制权与加州财富税安排是隐含动机；(3) 250 亿美元判罚 + 171 亿美元和解把"平台合规成本"变成了 AI 投入的竞争性负担。
- **不确定性**：C 类股目前只是"建立类别"，尚未实际发行，规模与定价未知；若最终不发行或规模远低于预期，则本判断的"融资压力"权重需下调。裁决上诉可能改变罚金。
- **Signals to monitor**：Class C 实际发行规模与用途披露；Q4 财报中 AI 相关折旧/资本化口径；Muse 分享功能重启时间与安全修复方案。

### 2) OpenAI 模型登陆 Google Cloud + ChatGPT Ads 扩至 26 国：模型层被"分销 + 变现"重新定价

- **核心事实 / 关键证据**：OpenAI 与 Google Cloud 宣布把前沿模型（GPT 6.1 Astra、Sol、Luna）与 Codex 工作流带入 Gemini Model Garden，并通过 Google Cloud Marketplace 提供；同日 ChatGPT Ads 扩展到 26 个新国家，累计 10 万+ 广告主，并公开 LLM 驱动的广告栈（理解对话意图、广告与答案分离）。另有 OpenAI/PerturbAI/Scripps 用数千个分布式 agent 挖掘数百万脑细胞数据。
- **我的判断**：这是"模型商品化"的关键一步——**当最前沿的模型出现在竞争对手的云货架上，模型本身的稀缺性就被渠道稀缺性替代**。对 Google 而言，这是把 GCP 做成"中立多模型底座"的战略（类似当年 Android 的中立性），短期牺牲 Gemini 的独占叙事，换取云消耗；对 OpenAI 而言，这是在 IPO 前把分发面铺到最大、并用广告把免费/低付费流量变现。广告栈的技术细节值得注意：把"广告与答案分离 + 对话意图建模"作为信任设计，说明 OpenAI 已把广告当作长期收入线而非试验。
- **不确定性**：模型在第三方云上的版本滞后、定价与配额未披露；广告收入 run-rate 无官方数字；"广告 vs 答案"的信任边界在监管（FTC/欧盟）下仍可能被挑战。
- **Signals to monitor**：Gemini Model Garden 上 OpenAI 模型的版本更新节奏；ChatGPT Ads 是否进入欧盟（GDPR/DSA 约束）；OpenAI 是否在 S-1 中单列广告收入。

### 3) 中国"双轨对冲"：~$35B 合规 Nvidia 订单 + DeepSeek 开源双栈 + DHS 禁令

- **核心事实 / 关键证据**：Reuters 口径显示腾讯、阿里、字节合计下单约 350 亿美元 export-compliant Nvidia RTX Pro 5500（约 300 万张），远超 Nvidia 计划产能；同日 DeepSeek 开源 DeepInfer 高性能推理框架（原生支持 Nvidia SM100 与华为 Ascend 950），HN 2300 分/881 评论；DeepSeek V4 发布据报带动华为 Ascend 芯片抢购；美国 DHS 下令联邦民事机构移除并排除 DeepSeek 产品，中方公开批评；中国 MOFCOM 据报道限制 AI 模型与芯片 IP 的出口转让。
- **我的判断**：三条信号合起来说明**管制的均衡不是"切断"，而是"合规管道 + 开源渗透 + 政治封禁"三线并行**。350 亿美元订单证明 Nvidia 仍是中国算力的主供给；DeepInfer 的双栈设计则是把"软件栈默认值"变成对冲工具——一旦 Ascend 成为 DeepSeek 系模型的默认后端之一，华为的生态锁定就从采购层下沉到开发者习惯层，这比芯片本身更难被管制。DHS 禁令则是政治层面的对价。
- **不确定性**：350 亿美元中实际可交付比例（据称约 10%）、SKU 细节（RTX Pro 5500 为工作站级而非训练级）均未确认；DeepInfer 的性能宣称缺第三方复现；DeepSeek 被列入 Entity List 的时点仍不确定。
- **Signals to monitor**：Ascend 950 月出货量与交期；DeepInfer 在非 DeepSeek 项目中的采用；BIS 是否把性能密度阈值进一步收紧至 RTX Pro 5500 档位。

### 4) NVIDIA GTC Berlin + Google Cloud Vera Rubin GA：算力供给扩张，但节奏在滑

- **核心事实 / 关键证据**：GTC Berlin 发布 RTX Spark（Windows PC 本地 agent）、DGX Spark（Linux 开发者）、DGX Station（企业 Linux，Windows 版 12 月）、DSX Pod 插件式模块化数据中心、cuDSS GA、FOX 工厂运营蓝图；Google Cloud 与 NVIDIA 宣布 Vera Rubin（A5X / NVL72 + ConnectX-9 + Virgo 网络 + 第四代液冷）**下月 GA**，并计划扩至欧洲。同期 Greenpeace 因"芯片流入俄罗斯无人机"扰乱黄仁勋主题演讲；NextDC 因盈利预警单日暴跌 44%，Nscale 安抚员工，Firmus IPO 失败后 Nvidia 洽谈注资。
- **我的判断**：产品线扩张是真实的，但**"GA 在下月"这句话本身是负面信号**——它意味着 Q3 内三家具名云客户完成 Vera Rubin 收货确认的里程碑大概率已滑入 Q4。同时 DSX Pod 是真正有结构性意义的产品：把"数据中心"做成可插拔模块，直接针对欧洲的并网与选址瓶颈；这也解释了为什么 Nvidia 要把叙事从"卖卡"转向"卖 AI 工厂"。
- **不确定性**：DSX Pod 的客户采用与交付周期；欧洲 sovereign cloud 伙伴（Nebius/Nscale/Gcore）的融资状况；Greenpeace 抗议是否引发出口合规审查升级。
- **Signals to monitor**：Vera Rubin 首批具名客户确认（Q4）；DSX Pod 首个欧洲主权云订单；Nvidia 对 Firmus/Nscale 的资本动作。

### 5) Tesla Q3：利润 -43%、Optimus 投产、车主 robotaxi 明年、Terafab 与 SpaceX 合并探索

- **核心事实 / 关键证据**：Q3 营收 280 亿美元（同比持平）、净利 17 亿美元（-43%）；费用因 Optimus、AI、自动驾驶上升，交付目标下调，储能收缩；Autonomous Driving VP Ashok Elluswamy 称车主明年可将自有车辆加入 robotaxi 车队；Optimus 已在加州开始生产；ASML 等设备商加速向 Tesla/SpaceX 的 Terafab 供货（目标 2028 年 Q3–Q4 量产）；Tesla 与 SpaceX 董事会已成立独立特别委员会探索合并，Musk 称"是个好主意"。
- **我的判断**：这是一份**把估值锚从汽车切换到"AI + 机器人 + 算力"的财报**，代价是当期利润率。要点在于三条时间表同时被给出（robotaxi 车主车队 2027、Optimus 量产爬坡、Terafab 2028 年底），而三条都缺乏独立验证——历史上 Tesla 的时间表系统性偏乐观。真正的新信息是"董事会特别委员会"：这是合并从口头进入程序化的标志。
- **不确定性**：车主车队涉及保险、责任、监管与远程运营，落地难度被低估；Terafab 2028 量产目标与 43% 利润下滑的融资能力存在张力；合并需股东与全球反垄断审查。
- **Signals to monitor**：Optimus 周产量（对照 5000 台/周的目标）；Terafab 设备到位与首次流片；合并的 S-4/委托书文件。

- **Authors / Lab:** 超长作者名单（机构标注 Unknown，但从作者构成看高度疑似 Meta FAIR）

### Evolving Agent Interfaces（Agent S4）
- **Authors / Lab:** Saaket Agashe 等，UC Santa Cruz / Agent S 团队
- **Source:** arXiv 2610.28601 / Hugging Face Daily
- **核心贡献:** 把"接口设计"本身变成 agent 能力——agent 可自主合成或演化更高效的 GUI/shell/API 交互方式，而非依赖人工搭建的工具链。
- **技术意义:** 直指 computer-use agent 的真实瓶颈：不是模型不够聪明，而是人给的接口太低效（逐格填表、打印两千行找函数）。若可验证，会显著改变 agent 工具层与 token 成本的工程假设。
- **Code/Demo:** 未见
- **信号强度:** medium（摘要截断，缺 benchmark 与泛化证据）

### Solving a 31-year-old grand challenge in mathematics – the KLS conjecture
- **Authors / Lab:** Microsoft Research
- **Source:** Microsoft Research Blog
- **核心贡献:** 据 MSR 口径解决 Kannan–Lovász–Simonovits 猜想（高维凸体等周不等式），直接约束 hit-and-run、ball walk 等随机采样算法的混合时间。
- **技术意义:** 这是理论计算机科学/高维几何的里程碑，为 MCMC、体积估计乃至部分 diffusion/score-based 采样的复杂性分析提供更紧的上界。对工程是间接的、长周期的。
- **Code/Demo:** 不适用
- **信号强度:** medium（仅博客口径，未见完整论文与同行评审；需核实是完整解决还是 polylog 近似）

### Specter: Fast MoE Inference via Quantization-Enabled Multi-Step Speculative Offloading
- **Authors / Lab:** Wenfeng Wang 等，上海交大（推断）
- **Source:** arXiv 2511.14102 / Hugging Face Daily

- **Code/Demo:** 有（待核）
