### 1) Jensen Huang 辞任 Nvidia CEO，叠加 GPU 走私与第三国执法

**核心事实 / 关键证据**
- 黄仁勋辞去总裁、CEO、董事职务，即时生效；CFO Colette Kress 任临时 CEO；董事会据报曾接触 Arm CEO Rene Haas。（SCMP / Wired / Bloomberg，多源）
- 内部请愿"Bring Back THE Boss"累计 1,600+ 条评论；HN 相关三帖 790/448/280 分，合计近 1,300 条评论。（Wired / HN）
- 供应链端：约 $11.4M Nvidia 硬件在加州—德州运输途中失踪；SemiAnalysis 类估算称约 1.5GW 被禁加速器入华；马来西亚调查再出口，新加坡就 917 台 AI 服务器采购起诉一名高管。
- 财务传导：Nvidia 在 229 家私营公司约 $48B 的投资组合（含 OpenAI、Anthropic）成为治理问题；VC 与创始人预期融资额度缩小、估值下调。

**我的判断**
这不是一次孤立的人事危机，而是**三重集中度同时暴露**：单一供应商（Nvidia 占 AI 算力）、单一强势创始人（黄仁勋同时是战略、路线图和华盛顿游说通道）、单一管制通道（H200/Blackwell 的许可体系）。前两类风险历来可以用降价、产能、游说对冲；第三类不能——因为它取决于政治上是否愿意继续给 Nvidia 例外。走私指控与第三国执法让这个例外的政治成本显著上升。

**不确定性**
- 辞职与丑闻细节目前为媒体报道，Nvidia 官方公告的措辞与董事会治理安排尚未看到完整版本。
- 1.5GW 走私估算是单点分析，量级可能与实际存在数量级偏差。
- 新任 CEO 是"永久"还是"临时转正"，决定了路线图（Vera Rubin 爬坡、Hugging Face 整合）的连续性风险大小。

**Signals to monitor**
- 永久 CEO 提名与是否来自外部（Arm 系 / 半导体老兵）vs. 内部晋升——外部空降会显著提高战略重置概率。
- 是否有客户（尤其 hyperscaler）公开宣布加速多元化采购或双供应商策略。
- BIS 是否就第三国再出口发布新的许可要求或实体清单动作。
- Nvidia 下一季 10-Q 的中国区收入与风险因子措辞变化。

### 2) OpenAI 推出 ChatGPT Wallet：agent 开始代用户花钱

**核心事实 / 关键证据**
- 面向美国 18 岁以上、美国账单地址、ChatGPT Pro 订阅者，支持 Amex / Chase / Mastercard / Visa 的合格美国卡。
- 覆盖 ChatGPT Work、Codex、Dots 三类 agent；机制为"用户批准 + 现有卡组织保护"。
- 官网原文：让 agent "with user approval and existing card protections" 完成购买。

**我的判断**
这是 agent 商业化的关键一跃：**过去 agent 的边界是"信息动作"，现在是"资金动作"**。OpenAI 的设计选择非常聪明——把审批权留给人、把风控责任留在卡组织，从而避免自己成为支付责任主体。但这也意味着**风险被外化给了卡组织和商户**：当 agent 发起的交易产生争议（误购、被提示注入诱导的购买、订阅陷阱），chargeback 归责规则并不存在。

**不确定性**
- 初始仅限美国 Pro，规模小、样本少，短期不会产生系统性支付风险数据。
- 卡组织是否接受"agent 代表持卡人发起交易"这一法律构造，目前完全未验证。
- 与 Apple Pay / Google Pay 的 agent 化路径是否形成标准竞争，尚早。

**Signals to monitor**
- 任一家卡组织发布 agentic commerce 规则或责任框架（已立为预测 P20261113-1）。
- 商户侧接入率与首批争议案例。
- OpenAI 是否把 Wallet 扩展到 Plus 免费层——这是它从"实验"变成"基础设施"的分水岭。

## 6. Papers & Research Frontiers

### Evolving Infra: Agent-Adaptive LLM Serving at Scale
- **Authors / Lab:** Hao Kang, Weili Xu, …, Ion Stoica, Song Han（机构未标注）
- **Source:** HuggingFace Daily / arXiv 2611.12304
- **核心贡献:** 提出 agent-adaptive 的 PD 分离式 serving 框架，用 agent 级运行时信号动态重分配 prefill/decode 算力并保留可复用 KV cache。
- **技术意义:** 直击 agentic workload 的核心经济问题——prefill/decode 负载不均 + KV cache 被驱逐。作者阵容（Stoica、Song Han）提升了可信度。若实验成立，对推理平台的吞吐/成本有直接价值。
- **Code/Demo:** 未提供
- **信号强度:** medium（摘要截断，缺量化收益与 benchmark 设置）

### SteerDistill: Quantizing LLM Agents via Closed-Loop Teacher Steering
- **Authors / Lab:** Genming Cui, Xiangyu Li, …, Ting Cao（关联 Nvidia）
- **Source:** HuggingFace Daily / arXiv 2611.13410
- **核心贡献:** 发现量化后的 agent 会"忽略任务要求或环境条件"，产生与全精度参考偏离的环境转移，并用闭环教师引导来纠正这一行为偏差。
- **技术意义:** 这是把 agent 量化从"权重精度问题"重新定义为"行为保真问题"，方法论上比单纯 PTQ/QAT 更贴近 agent 的真实失效模式。对低成本 agent 部署有直接工程含义。
- **Code/Demo:** 未提供
- **信号强度:** medium

### ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping
- **Authors / Lab:** Joseph Marvin Imperial, Daniel Slate, Noam Kolt（Kolt 关联 University of Toronto）
- **Source:** HuggingFace Daily / arXiv 2611.11306
- **核心贡献:** 首个从法律合规角度评估 agent 的 benchmark，测量 agent 在抓取任务中是否遵守 ToS 与 robots.txt；报告称多数闭源与开源 agent 合规率低于 5%。
- **技术意义:** 把 agent 评测从"任务成功率"扩展到"法律与治理维度"。这个 <5% 的数字，配合今天 OpenAI Wallet 让 agent 代用户交易，构成一个值得警惕的组合：**agent 的能力边界扩张速度快于其合规基线建立速度。**
- **Code/Demo:** 未提供
- **信号强度:** medium（结论强，但 benchmark/代码未确认公开）

### Classical Energies Learn to Reason 1,000x Faster than Looped Models
- **Authors / Lab:** Benjamin Hoover, Hugh Blayney, James C. R. Whittington（关联 Nvidia）
- **Source:** arXiv cs.AI 2611.17309
- **核心贡献:** 用能量下降（descent on an energy）替代 looped model 做推理，声称训练更稳、内置早停、算力随问题难度自适应，且在 Sudoku-Extreme / Maze-Unique 类任务上快约 1,000 倍。
- **技术意义:** 如果成立，这是对"推理靠堆循环层数"这一主流范式的直接挑战，且方向对算力成本友好。但"1000x"这类数字需要独立复现才可信。
- **Code/Demo:** 未提供
- **信号强度:** medium（潜力大，量化声明激进）

## 7. Startup / Unicorn Watch

- **我的判断：真技术 + 强叙事，但"叙事包装"成分在上升。** 核心风险不是模型能力，而是"算力承诺规模 vs. 供应商融资能力"的错配。置信度：中。

**LangChain（估值 $3B）**
