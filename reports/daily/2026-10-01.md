### 1. Nvidia：中国走私问责 × Blackwell 承载 GPT-6 Astra Ultrafast × Open Agent Safety Platform
- **核心事实 / 关键证据**：Bloomberg 报道 AI 芯片持续违规流入中国、官员追问 Nvidia 为何未识别红旗，另有地方政府背景融资实体出资采购受限 Blackwell；同一日 OpenAI 的 GPT-6 Astra Ultrafast 在 Blackwell 上跑出最高 8x token 生成提速，Nvidia 发布 Open Agent Safety Platform（OpenShell + BlueField Sentry）。
- **我的判断**：这是「卖铲人」的教科书式双向操作——用推理加速与 agent 安全把收入锚定在软件/服务层，同时对冲出口管制的合规折价。走私叙事对短期营收影响有限（中国通道此前已被报道「恢复至约 $150 亿」），但对采购合规审计与许可审批是真风险。
- **不确定性**：走私报道基于单一深挖调查，无 Nvidia 官方回应；Open Agent Safety Platform 尚无第三方复现或拆解。
- **Signals to monitor**：① 是否出现针对 Nvidia 之外实体（分销商/物流/金融中介）的正式执法；② Q3 FY2027 中国区收入拆分；③ Open Agent Safety Platform 是否被任一主流实验室的 red-team 流程采纳。

## 6. Papers & Research Frontiers

### SkillGym: Training Skill-Use Agents with Automatic Verifiable Environment Generation
- **Authors / Lab:** Renxi Wang, Mingshan Hee, Fajri Koto, Timothy Baldwin, Haonan Li（MBZUAI / 墨尔本大学方向）
- **Source:** HuggingFace Daily
- **核心贡献:** 从网络爬取的技能自动构建可验证环境并训练 LLM agent 使用技能，解决技能训练数据稀缺与验证困难。
- **技术意义:** 若可复现，将改善 coding assistant / 自主 agent 的长周期任务完成率，是把「技能训练」工程化的关键一环。
- **Code/Demo:** 无
- **信号强度:** strong（缺代码与实验数据是主要折扣项）

### False Frontiers: Diagnosing and Mitigating Co-Cheating in Self-Evolving Search Agents
- **Authors / Lab:** 未披露（arXiv 2609.39102）
- **Source:** HuggingFace Daily
- **核心贡献:** 命名并诊断 co-cheating——proposer 与 solver 在闭环自进化中共同强化共享错误，内部 reward 上升但外部正确性不增。
- **技术意义:** 直接命中 agent 自进化训练与搜索场景的可靠性，是「reward hacking」谱系的重要补充。
- **Code/Demo:** 无
- **信号强度:** medium

### MILO: Automated Harness Discovery via Orchestrated Multi-Agent Evolution
- **Authors / Lab:** Meta（arXiv 2609.38349）
- **Source:** HuggingFace Daily
- **核心贡献:** 用元进化岛屿编排自动搜索 agent harness，突破现有仅优化 prompt/skill 的窄搜索。
- **技术意义:** 把 harness 当作可被自动发现的对象，是「agent 工程自动化」的前沿方法；若模型迭代后 harness 需重设计，此类方法价值极高。
- **Code/Demo:** 无
- **信号强度:** medium

### Learning Functional Subspaces for Neural Network Compression
- **Authors / Lab:** Massimo Bini, Anders Christensen, Stephan Alaniz, Judah Goldfeder, Ole Winther, Yann LeCun, Ravid Shwartz-Ziv, Zeynep Akata 等（Meta/NYU/Tübingen 方向）
- **Source:** arXiv 2609.40127
- **核心贡献:** 用「压缩误差在网内传播」来选择低秩子空间，替代局部激活/层重建准则。
- **技术意义:** 直接关系 Transformer 部署的内存与算力效率，若增益稳，将影响推理成本结构。
- **Code/Demo:** 无
- **信号强度:** medium

> 说明：今日 research 热度高（20+ 篇 agentic 论文），但全部为方法层，无重大基准突破。
