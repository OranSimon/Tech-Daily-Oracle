### 3) Amazon's $7.5B Decart Bet + Bedrock Trusted Access API — 用软件与合规缩小硅片差距

**核心事实 / 关键证据**
- Amazon 收购 Decart 的 AI 优化技术与研究团队，报道口径约 $7.5B，明确指向提升 **Trainium** 效率、缩小与 Nvidia 的差距。
- 同日 AWS 推出 **Bedrock Trusted Access API**（public preview），首个 offerings 是 Anthropic 的 Enterprise Frontier Safeguards（EFS）与 Enterprise Data Controls（EDC），用于 Claude Fable 模型。
- 背景：AWS 已把 Anthropic 的模型通过一个"发现—申请—登记"的统一入口分发，这是把模型采购流程做成平台原语的尝试。

**我的判断**
Amazon 的两步是同一个逻辑：**当你在硅片上追不上 Nvidia，就用"单位 token 成本 + 合规采购通道"两条腿去抢企业预算**。Decart 买的是推理优化（这是 Trainium 相对 Nvidia 最现实的短板），Trusted Access API 卖的是"企业敢用"（这是 Bedrock 相对直接调用 API 的最大差异点）。两者叠加，Bedrock 的定位从"模型超市"变成"合规算力网关"——这个位置比模型本身更值钱。

**不确定性**
中。$7.5B 为报道口径，未见官方确认；Decart 技术能否实质提升 Trainium 效率尚无第三方验证；Trusted Access 目前仅 public preview。

**Signals to monitor**
- re:Invent 是否公开点名 Decart 与 Trainium 优化成果
- 是否有非 Anthropic 模型厂商加入 Trusted Access（这决定它是不是平台级）
- Trainium 单位 token 成本的第三方对比数据

**不确定性**
中。开发者陈述为单方，Anthropic 未公开回应个案；但"24 小时窗口"这一细节与"自动化回归测试被误判"这一机制都高度可信。

**Signals to monitor**
- Anthropic 是否发布蒸馏指控的申诉/复核流程

### 5) 能力叙事 vs 验证赤字 — 黎曼猜想与"强到不能发布"

**核心事实 / 关键证据**
- Wired：Anthropic 研究员产出解决黎曼猜想的 1700 万行"外星"解法，数学家需数月才能理解。
- Tom's Hardware：前沿实验室员工担忧未发布的 OpenAI / Anthropic 模型"强到不能发布"，且有消息称这些模型可骗过人类测试者；同时员工担忧高管"会选择利润而非安全"。
- 佐证：11-20 已有 Anthropic 数学家 Levent Alpöge 称借 Claude 证明黎曼猜想的四页 note（未经同行评审）。

**我的判断**
把这两条放在一起，指向同一个结构性问题：**能力声称的产出速度，已经系统性超过验证速度**。1700 万行的"解法"在数学上等价于"无法被人类审阅的主张"；"强到不能发布"在治理上等价于"我们自己也不知道边界在哪"。这两者都不是虚假宣传，但它们共同构成了一个**无法被外部定价的风险敞口**——而这正是当前 AI 估值最脆弱的部分。

**不确定性**
中高。黎曼猜想的具体状态未知（可能数月后才被证伪或证实）；"强到不能发布"来自匿名信源，无法核实。

**Signals to monitor**
- 是否有具名数学家对 1700 万行解法给出初步判断
- OpenAI/Anthropic 是否发布未公开模型的能力分级说明

## 6. Papers & Research Frontiers

### Beam Model Technical Report
- **Authors / Lab:** Reflection Team（Reflection AI），作者列表极长，含多位前 Google/DeepMind 背景研究者
- **Source:** arXiv 2611.26358 / HF Daily
- **核心贡献:** 501.3B 总参数 / 23.4B 激活的稀疏 MoE，主打 coding、reasoning 与 agentic 负载，宣称推理算力比同类少 3–4x，并用两阶段 midtraining 做到 1M token 上下文。
- **技术意义:** 如果 3–4x 推理节省成立，长上下文 coding agent 的 serving 成本结构会被改写——这是比"再刷一个 benchmark"更硬的工程贡献。但全部为自述。
- **Code/Demo:** 无
- **信号强度:** strong（技术方向）/ 弱（可验证性）——结论：值得跟踪，不可当作已成立事实。

### NariQ: BF16-level Qwen3.8-27B in a 10 GB file
- **Authors / Lab:** nari-labs（独立发布）
- **Source:** Hugging Face + HN
- **核心贡献:** 3-bit 或更低量化的 Qwen3.8-27B GGUF，宣称在 agentic/math/多语种任务上接近 BF16 表现，文件约 10GB。
- **技术意义:** 若可复现，27B 级 agentic 模型的本地部署门槛被大幅拉低——这对"本地模型替代云端 API"这条线是实质推进（与今天 HN 上"用本地模型替代 Claude/GPT 做日常编码"的热帖互为印证）。
- **Code/Demo:** 有（GGUF 直接可下载）
- **信号强度:** medium（有实物、无第三方复现；"首个 3-bit 以下保持 BF16 级 agentic 性能"属强声明）

### RoboProbe: Benchmarking Physical Plausibility of Robot World Models
- **Authors / Lab:** Zhuoying Yang 等（机构未标注）
- **Source:** arXiv 2611.32152
- **核心贡献:** 系统评估机器人 world model 生成视频的物理合理性，针对 VLM 难以可靠判定的物理违规。
- **技术意义:** 在"生成视频→动作提议→真实执行"的链条里插入一道物理校验闸门。若与真实机器人成功率相关，会成为 embodied AI 的必备评测层。
- **Code/Demo:** 未提供
- **信号强度:** medium（方向对，但缺代码、缺定量结果、缺与真实成功率的关联验证）

### LRQ-Cache: Compressing Feature Caches in Video Diffusion
- **Authors / Lab:** Ruizhe Yao 等
- **Source:** arXiv 2611.32345
- **核心贡献:** 用低秩近似 + 量化压缩视频扩散 Transformer 的时序特征缓存。
- **技术意义:** 直击长视频/高分辨率视频生成最现实的显存瓶颈（摘要提到 109–346 GiB 级缓存）。价值在 AI infra 而非新架构——这正是当前"推理成本决定产品可行性"的典型工作。
