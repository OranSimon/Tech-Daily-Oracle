## 6. Papers & Research Frontiers

### DiffusionGemma Technical Report
- **Authors / Lab:** DiffusionGemma Team, Google DeepMind
- **Source:** arXiv / HuggingFace Daily
- **核心贡献:** 基于 Gemma 4 MoE 微调出的离散扩散语言模型，通过迭代分块精炼实现 256 token 并行解码。
- **技术意义:** 若速度收益与质量损失可验证，这是自回归解码范式的首个大规模替代物——推理延迟与吞吐都会重写；NVIDIA 已为其做 RTX/DGX 优化，说明产业侧在认真对待。
- **Code/Demo:** 可用
- **信号强度:** strong

### Qwen-CUA: Native Computer Use for (almost) Everything
- **Authors / Lab:** Alibaba Qwen Team
- **Source:** arXiv
- **核心贡献:** 397B-A17B MoE 电脑操作 Agent，仅靠截图与键鼠动作操作软件，不依赖 DOM 或任务专用 API。
- **技术意义:** 这是"无需 API 代理层即可操控任意软件"路线最具规模的公开实现；与 Anthropic Computer Use 正面竞争，且开源权重将显著拉低进入门槛。标题的 "almost everything" 需独立复现验证。
- **Code/Demo:** 可用
- **信号强度:** strong

### SAF-OPD: Stable Advantage Fusion for On-Policy Distillation
- **Authors / Lab:** Alibaba 等
- **Source:** HuggingFace Daily / arXiv
- **核心贡献:** 提出 RLVR 与 on-policy distillation 两种优势信号融合时的熵坍缩问题，并给出稳定融合方法（SAF-OPD）。
- **技术意义:** 这是《DeepSeek V4 蒸馏争议》之后最重要的训练方法论文之一：它把"蒸馏何时失效"从经验问题变成可数学表述的校准问题。对开源阵营以小搏大的训练路线有直接工程价值。
- **Code/Demo:** 未确认
- **信号强度:** medium-strong（摘要截断，实验细节待验证）

### AtumAI: A Principled Framework for Agentic Generation of Datacenter Control-Plane Policies
- **Authors / Lab:** Microsoft Research
- **Source:** arXiv
- **核心贡献:** 用形式化问题构造 + LLM 驱动搜索，自动生成数据中心控制面策略。
- **技术意义:** 这是"Agent 进入基础设施运维"的少见正式化尝试，直接把控制面策略生成从数月原型压缩为自动化验证。微软研究院背景 + 方向明确，但无代码，需跟踪。
