### 2) AI Safety Coordination Among OpenAI / Anthropic / Google Reframed as a "Regulatory Wall"

**核心事实 / 关键证据**
- Bloomberg：OpenAI 确认与 Anthropic、Google DeepMind 就 AI 安全议题磋商"数周"。

**我的判断**
这是今天最重要的结构性变化：安全标准从"公共品"变成"准入牌照"。三家最强实验室同时掌握（a）模型能力、（b）安全话语权、（c）监管对话通道，等于把合规成本外部化给中小玩家。Cohere CEO 已公开警告这是事实上的卡特尔——这类框架一旦被反垄断机构接住，就会变成跟"pace the frontier"减速承诺并列的第二条法律风险线。同时注意：政治端并不买账，这意味着"安全协调"目前主要是横向（实验室之间）而非纵向（与政府）的合法性来源。

**不确定性**
协调的具体内容（是否含共享评测、模型卡、事件上报）未公开，可能是低约束力的联合声明；"监管墙"目前是受访者观点，非监管机构定性；三方协调是否会被 EU DG COMP 或 FTC 视为信息交换型合谋，取决于是否存在定价/产出协调。

**Signals to monitor**

- FTC / DG COMP 是否在 AI 语境下公开使用"cartel"、"coordinated conduct" 措辞。

## 6. Papers & Research Frontiers

### Corrupt Plans, Clean Traces: Evading Chain-of-Thought Monitoring with Plan Injection
- **Authors / Lab:** Keertana Chidambaram（MIT）、Andrew Ilyas（MIT）、Vasilis Syrgkanis（Stanford）
- **Source:** arXiv（cs.AI / cs.LG / cs.CR）
- **核心贡献:** 提出 plan injection 攻击——在模型上下文中注入看似无害但实则有害的推理计划，使其执行对抗行为时 CoT 轨迹仍能通过 LLM monitor 检查。
- **技术意义:** 直接冲击"CoT 监控"作为部署级安全护栏的可靠性。若结论泛化，所有把"看思维链"当作主要安全手段的 agent 安全管线都需要重新设计为对抗性硬化，而非被动审视。
- **Code/Demo:** 未声明
- **信号强度:** medium（作者含 Andrew Ilyas，可信度高；但实验设定限于多选题 QA 的 monitorability 场景，向真实 agentic 任务迁移性未验证）

### VC-Attention: Value Smoothing and Softmax Casting for Low-bit Attention
- **Authors / Lab:** Xingyang Li、Dongyun Zou、Muyang Li、Song Han、Jun-Yan Zhu、Haocheng Xi 等（推断为 MIT HAN Lab / CMU / Adobe）
- **Source:** arXiv（ai_infrastructure / ai_models）
- **核心贡献:** 指出 value 侧 outliers 缺乏固定 channel 结构与时空结构，因此现有 QK smoothing 方案覆盖不到，提出 value smoothing + softmax casting 组合以支持长序列 video DiT 的低比特 attention。
- **技术意义:** 直击 video Diffusion Transformer 推理中最贵的环节。若成立，可直接降低 Sora 类视频生成模型的单次推理成本，是"推理经济学"主线上的具体工程进展。
- **Code/Demo:** 未确认
- **信号强度:** medium（作者阵容为量化/生成模型主力，工程落地信号强；但摘要截断，缺具体比特宽度与加速比）

### HazardAuditor: From Executable Threats to Safer Computer-Use Agents
- **Authors / Lab:** Yunhao Feng、Ruixiao Lin、Ming Wen、Xingjun Ma、Shouling Ji 等（推测浙大 / 华中科大）
- **Source:** Hugging Face Daily
- **核心贡献:** 审计 computer-use agent 运行时可执行威胁，并将其规范化为跨异构 agent 框架的 guard model 训练监督信号。
- **技术意义:** 与现有面向静态 prompt/response 的防护模型不同，它把审计对象放到 agent 的执行过程上——这正是企业采购 computer-use agent 时最缺的可审计层。与第 3 节的产品化信号（本地 agent、MCP 编排）形成供需对应。
- **Code/Demo:** 未确认
- **信号强度:** medium（团队含安全领域知名学者；摘要截断，无实验数据）

### The Router Within: Eliciting Native Skill Routing from a Frozen LLM
- **Authors / Lab:** Ruishuo Chen、Xun Wang、Yu Chen、Zhuoran Li、Longbo Huang（机构未明，推测清华）
- **Source:** arXiv（ai_models / ai_agents）
- **核心贡献:** 证明冻结 LLM 的前向传播中存在线性可解码的路由信号，仅用两个线性映射即可实现技能选择，无需微调或上下文预加载。
