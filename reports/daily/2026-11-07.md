## 3. Top Developments

### Nvidia 的中国风险升级为反间谍与国会调查
- **核心事实 / 关键证据：** FT 与 TechCrunch 报道美国情报备忘录称，中国国家安全部招募 Megaspeed 高管 Alice Huang 对黄仁勋实施"蜜罐"行动；Tom's Hardware 报道黄仁勋已被正式传唤至国会作证；The Verge 转引 NYT 指出获批接收 H200 的 New Matrix 办公场所为空壳，涉及约 20 亿美元芯片走私指控；台积电公开否认"应 Nvidia 要求探索 3D DRAM"。
- **我的判断：** 这是本季度 Nvidia 最重要的单一事件簇。三个信号叠加的后果不是罚款，而是**许可政策的可逆性被证明**——已经批出去的 H200 许可可以因为国会听证而重新审视。对 Nvidia 而言，中国收入已从"能卖多少"变成"随时归零"；对 Huawei 而言，这是第三次免费获得政策红利。
- **不确定性：** 核心指控均源自匿名情报来源与转述报道，Nvidia 未公开回应细节；"传唤"是否已升级为正式听证尚不明确。台积电的否认反而说明 3D DRAM 这条内存叙事目前缺乏证据支撑，不宜当作既成事实。
- **Signals to monitor：** BIS 是否撤销/拒绝续期任何已批 H200 分销商许可；参议院银行委员会或众议院外交委员会是否排期听证；Nvidia 下一份 10-Q 是否新增"许可正在被复审"类风险语言。

### Claude Code 的信任赤字：邮箱外发 + 1,122 个公开仓库泄密
- **核心事实 / 关键证据：** GitHub issue #107757 被推上 HN 头条（1590 分 / 514 评论），指控 Claude Code 把用户邮箱地址发送给其访问的网站；apiiro 同日发布研究称 "Don't Ask Again" 授权模式导致密码等敏感信息泄露至 1,122 个公开 GitHub 仓库。
- **我的判断：** 两个缺陷方向相反但同源——一个是"默认外发过多"，一个是"默认授权过宽"。这说明 Claude Code 的默认值设计缺少威胁建模，而不是缺少测试。在 agent 从"补全"变成"代你操作"的阶段，默认值就是产品；这一天的代价会体现在企业采购的安全问卷里，而不是 PR 稿里。
- **不确定性：** 邮箱外发是否属于预期遥测行为（部分工具确实上报 Referer/UA）尚待 Anthropic 定性；1,122 个仓库中实际可利用的凭据比例未知。
- **Signals to monitor：** Anthropic 是否在 30 天内发布 changelog 或安全公告；是否有欧盟 DPA 就该行为发出问询；企业客户是否公开限制 Claude Code 后台 agent。

### Tesla 结束 Cybertruck，产能转向 Cybercab
- **核心事实 / 关键证据：** Musk 于 11 月 6 日宣布明年"winding down" Cybertruck 生产，为 Cybercab 腾出产能；HN 1124 分 / 2021 评论；The Verge 定性为"令人羞辱的退场"，TechCrunch 将其与中期选举后 Musk 的政治处境、数据中心争议并置。

- **不确定性：** "wind down" 的具体时间与是否有最终车型/纪念版未定；Cybercab 产能爬坡与各州运营许可进度未披露。
- **Signals to monitor：** Giga Texas 产线改造的第三方报道；Cybercab VIN 注册记录；NHTSA 是否将学区投诉升级为正式 PE/EA。

### Microsoft Research AI Frontiers 解散 vs METR 的"AI 加速 AI 研发"
- **核心事实 / 关键证据：** 多个来源（hunch.net 及 archive 链接）报道 MSR 的 AI Frontiers 团队被宣告结束、研究员 John Langford 离职；同日 METR 发布 11 周调查，称 Anthropic 的模型改进速度约为一年前两倍且未见放缓，部分研究者对此表示不安。
- **我的判断：** 这两件事放在一起才是信号：能力曲线在加速，而承载长期研究的组织形态在退潮。前者意味着递归改进的实证正在积累，后者意味着这类工作的执行主体正在从大公司研究院转向少数前沿实验室与产品团队。对 Google DeepMind 的人才外流叙事是一个镜像对照——不是只有 DeepMind 在失血。
- **不确定性：** MSR 团队解散目前仅见于二级来源与个人博客，微软未官方确认；METR 结论依赖单一方法论（time-horizon），且 Anthropic 是唯一受测对象，泛化性有限。
- **Signals to monitor：** 微软官方是否确认 AI Frontiers 状态；MSR 是否出现 2 位以上 principal researcher 级离职；METR 后续是否把同一方法应用到 OpenAI/Gemini。

### AI 基建的执行摩擦：3D DRAM 否认、Crusoe 出售、CoreWeave 转向州政府
- **核心事实 / 关键证据：** 台积电否认探索 3D DRAM 并称该技术距市场可行性仍有数年；Crusoe 将陷入困境的怀俄明 AI 数据中心项目卖给 Google；CoreWeave 致函德州州长当选人寻求数据中心合作；中期选举后数据中心面临的政治阻力上升（Michigan 当选议员推动联邦暂停令、欧洲抗议）。

## 6. Papers & Research Frontiers

### WeLM-Image: A Unified Image Generation Model towards Visual Intelligence
- **Authors / Lab:** Canmiao Fu 等（腾讯 / WeChat，机构为推断）
- **Source:** HuggingFace Daily / arXiv 2611.07392
- **核心贡献:** 用 Mixture-of-Transformers 架构（共享注意力、分离理解与生成参数）把多模态理解融入文生图、指令编辑与多参考合成，目标单 GPU 部署。
- **技术意义:** 若"单 GPU + WeChat 级消费产品"成立，图像生成的产品化门槛会被显著压低——这是把图像模型从"云端大模型"拉向"端侧功能"的路径，与今日 Claude Code / agent 事件合起来看，说明 AI 能力正在往"可嵌入"而非"可演示"方向走。
- **Code/Demo:** 未确认开源
- **信号强度:** medium（摘要被截断，无公开 benchmark，且 arXiv ID 与时间不一致，需核实）

### The SIMPLE Law for Energy Cost of LLM Inference
- **Authors / Lab:** Hiari Pizzini Cavagna 等
- **Source:** HuggingFace Daily / arXiv 2611.03330
- **核心贡献:** 给出 LLM 推理能耗的闭式复杂度表达式（计算 + 显存访问），并刻画 KV-cache 导致的 per-token 成本非线性增长。
- **技术意义:** 这是把"能耗"从实测回归变成可解释公式的一次尝试。对推理调度、容量规划、芯片/系统协同设计都有直接价值——尤其在 token 单价崩塌、毛利结构坍塌的当下，"每 token 能耗"正在变成比"每 token 智能"更硬的经营指标。
- **Code/Demo:** 无
- **信号强度:** medium（缺少跨硬件、跨架构验证）

### D3D: Decoupled Diffusion Drafting for Asynchronous Speculative Decoding
- **Authors / Lab:** Baoyou Chen 等
- **Source:** HuggingFace Daily / arXiv 2611.06425
- **核心贡献:** 用独立的 diffusion drafter 摆脱对 target model hidden states 的依赖，使 drafting 与 verification 可异步并行。
- **技术意义:** 直击现有 target-conditioned diffusion drafter 的串行瓶颈。若长 accepted prefix 能在真实 serving 中维持，这是推理吞吐的可观改进；但 speculative decoding 的收益高度依赖 benchmark 条件。
- **Code/Demo:** 无
- **信号强度:** medium（缺与 EAGLE / Medusa 的完整对比）

### SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization
- **Authors / Lab:** Qile Jiang, George Em Karniadakis（Brown University 推断）
- **Source:** HuggingFace Daily / arXiv 2611.08483
- **核心贡献:** 用数百个低成本 agent 在潜空间内推理（不解码思维链）来加速 LLM 引导的进化式程序搜索。
- **技术意义:** 方向正确——进化式搜索的成本瓶颈就是"每轮都要生成长 CoT"，潜空间推理把它绕开。若可复现，这是"AI 做科学发现"成本曲线的一次下移；但目前只有摘要级信息，且无代码。
- **Code/Demo:** 无
- **信号强度:** medium（重要性评分高但缺乏验证证据，谨慎解读）

## 9. China Tech

**技术进展：DeepSeek 继续走"效率优先"路线，而不是算力优先。** 今日披露两项：一是 arXiv 2611.03768 提出多层 indexer（重叠选择 + 注意力共享），专门解决 DSA 稀疏注意力在长上下文下的真实瓶颈——不是稀疏注意力本身贵，而是每层的 lightning indexer 要扫全 KV cache 去选 top-k=2048，长上下文时索引扫描而非注意力成为主成本。二是开源 deepseek-ai/deepseek-harness（"Everything is a Plugin"），把 agent loop、工具与评测脚手架做成插件化 harness。

**我的判断：** 这两件事的价值不在单点，而在路线选择——DeepSeek 在优化"推理成本曲线"（更便宜的长上下文、更轻的 agent 工具层），而不是在拼原始 dense 预训练 FLOPs。在出口管制下这是唯一理性路线，且正在被整个中国开源生态复用（论文明确指出 DSA 同时用于 DeepSeek-V3.2 与 GLM-5 家族）。

**供应链与芯片约束：** 今日 Nvidia 侧的空壳买家（New Matrix）报道是关键——它说明"批出去的许可"并未转化为可信的最终用途。对中国的直接影响是双向的：短期进口渠道被更严审查，中期进一步锁死 Huawei Ascend 的国内需求（ByteDance/Alibaba/Tencent 已在扫货）。注意一个矛盾信号：黑市 Nvidia 价格与 Ascend 溢价同时存在，说明双栈对冲而非单线替代仍是主流策略。

**国内外竞争对比与路线差异：** 美国前沿实验室在"能力 + 安全叙事"，中国在"成本 + 分发 + 工具层"。DeepSeek 的 harness 直接对标 Claude/OpenAI 的 agent SDK，是第一次在工具层而非模型层正面竞争。这条线的胜负不取决于 benchmark，而取决于第三方 agent 框架会不会把 deepseek-harness 当依赖。

**政策影响：** 半导体出口管制的执行正当性今日被两件事同时削弱又强化——空壳买家削弱（说明漏洞真实存在），国会传唤强化（说明政治意愿在上升）。结论：政策会更严，但执行成本更高。
