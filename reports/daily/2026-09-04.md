## 6. Papers & Research Frontiers

### Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments
- **Authors / Lab:** Jie Wu 等（Alibaba affiliation 明显，涉及 Qwen/通义团队）
- **Source:** arXiv 2609.04148 / Hugging Face Daily
- **核心贡献:** 从已有 terminal agent 轨迹中提取工具执行历史，把「单条冻结轨迹」转化为可复用、可验证的训练环境。
- **技术意义:** 正视 agent 后训练「真实环境稀缺」的瓶颈；若保真度可靠，这类方法能把代码 agent 训练数据从「静态 demo」放大为「可交互环境」。
- **Code/Demo:** 未披露
- **信号强度:** medium-high

### WHALE: A Simple Recipe for Joint Harness-Weight Optimization
- **Authors / Lab:** Haechan Kim 等（Stanford 相关团队）
- **Source:** arXiv 2609.00196 / Hugging Face Daily
- **核心贡献:** 提出对「模型权重 + 可执行 harness 代码」做联合优化的简单交替方案，跳出只调 prompt/权重 的局限。
- **技术意义:** 如果成立，它减少 agent harness 设计的人工工程，并直接影响软件、具身场景的 agent 自动化能力；本次论文潮中「harness 与权重联合优化」主题显著升温。
- **Code/Demo:** 标注有 code，但地址与可用性待验证
- **信号强度:** strong（方法新颖）、medium（复现待确认）

### SWE-Gate: Passing Functional Tests Is Not Enough for Software Engineering Agents
- **Authors / Lab:** Xin He 等
- **Source:** arXiv 2609.04167v1
- **核心贡献:** 提出仓库级 benchmark，要求 coding agent 满足「代码评审派生的验收约束」，而不只是通过功能测试。
- **技术意义:** 直接拷问当前编码 agent 的评测方式——「测试通过」不等于「人类 reviewer 会接受」。这会使 coding assistant 从优化 test pass rate 转向 review acceptance，对 Cursor/Copilot/Codex 产品评价影响直接。
- **Code/Demo:** 暂无
- **信号强度:** medium（benchmark 类，无代码会限制短期影响力）

### HarnessDev: Can LLMs Create and Evolve Their Own Agent Harness?
- **Authors / Lab:** 多机构协作（作者列表含多名华人研究者）
- **Source:** arXiv 2609.01437 / Hugging Face Daily
- **核心贡献:** 首个系统评估 LLM 能否「自行创建与演进 agent harness」的 benchmark。
- **技术意义:** 是「模型自举开发能力」的度量工具，可能把 agent 演进研究从任务表现层面推到系统设计层面。
- **Code/Demo:** 未披露
- **信号强度:** medium
