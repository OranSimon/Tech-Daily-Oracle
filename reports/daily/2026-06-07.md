## 6. Papers & Research Frontiers

### SePO: Self-Evolving Prompt Agent for System Prompt Optimization
- **Authors / Lab:** Wangcheng Tao, Han Wu, Weng-Fai Wong
- **Source:** arXiv 2606.04465 / HuggingFace Daily
- **核心贡献:** 提出自引用优化循环，将 prompt agent 自身的 system prompt 也纳入优化目标，形成完全自动化的递归 prompt 改进机制——现有方法均只优化 task agent 而保留 prompt agent 为静态人工设计。
- **技术意义:** 直接适用于生产 LLM agent pipeline，可显著减少人工 prompt 工程迭代成本。方法模型无关，通用性强。
- **Code/Demo:** 未确认开源
- **信号强度:** medium

### Code2LoRA: Hypernetwork-Generated Adapters for Code Language Models
- **Authors / Lab:** Liliana Hotsko, Yinxi Li, Yuntian Deng, Pengyu Nie
- **Source:** arXiv 2606.06492 / HuggingFace Daily
- **核心贡献:** 用 hypernetwork 动态生成 repository 级别的 LoRA adapter，在推理时实现零额外 token 开销的项目级代码 LLM 适配——解决了 RAG 方案消耗大量 context token 而 per-repo 微调成本极高的双重瓶颈。
- **技术意义:** 对 GitHub Copilot 类产品架构有直接参考价值；engineering-ready 思路，适合 6-12 个月内产品化。
- **Code/Demo:** 未确认开源
- **信号强度:** medium

### MLEvolve: Self-Evolving Framework for Automated ML Algorithm Discovery
- **Authors / Lab:** 多机构（14位作者）
- **Source:** arXiv 2606.06473 / HuggingFace Daily
- **核心贡献:** 提出 LLM 驱动的端到端 ML 算法自动发现框架，解决现有 MLE agent 的跨分支信息孤立、无记忆搜索、缺层级控制三大问题，引入自进化多 agent 协作机制。
- **技术意义:** 若自进化 ML 算法发现能落地，意味着 AI 系统将在无人工介入的情况下改进自身的训练方法——这是 long-horizon agent 能力的真实压测场景。
- **Code/Demo:** 未确认开源
- **信号强度:** medium

### AdaCodec: A Predictive Visual Code for Video MLLMs
- **Authors / Lab:** Haowen Hou 等（含 Nan Duan，Microsoft Research Asia 背景），机构未知
- **Source:** arXiv 2606.02569 / HuggingFace Daily
- **核心贡献:** 借鉴视频编码 I-frame/P-frame 思想，仅在场景变化显著时传输完整帧，否则用紧凑差异 token 替代，大幅压缩 Video MLLM 的视觉 token 数量。
- **技术意义:** 直接降低视频理解模型推理成本、扩大可用视频上下文窗口；思路来自传统编解码，工程实用性高。
- **Code/Demo:** 未开源
- **信号强度:** medium
