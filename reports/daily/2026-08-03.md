## 6. Papers & Research Frontiers

### SAF-OPD: Stable Advantage Fusion for On-Policy Distillation
- **Authors / Lab:** Alibaba（Yifan Ding 等 10 名作者）
- **Source:** Hugging Face Daily Papers / arXiv 2607.29209
- **核心贡献：** 解决 RLVR 与在线蒸馏（OPD）融合时的熵崩溃问题，提出 SAF 通过动态校准两种优势信号的幅度不匹配，实现两者互补而非相互破坏。
- **技术意义：** 对 Qwen3.8-Max 等使用 RLVR+蒸馏联合训练的模型有直接工程价值；解决了一个阻碍"强教师辅助+自主探索"联合训练的实际瓶颈。
- **Code/Demo:** available（Hugging Face 链接）
- **信号强度：** medium

### Memory Decoder at Scale: A Pretrained, Parametric Long-Term Memory
- **Authors / Lab:** Alibaba（Rubin Wei 等）
- **Source:** Hugging Face Daily Papers / arXiv 2607.27919
- **核心贡献：** 将参数化长期记忆模块扩展至 6.9B 参数、300B tokens 预训练规模，同时提出替代 Faiss 流水线以解决规模化索引成本问题。
- **技术意义：** 若能集成至 Qwen 产品线，可使 LLM 在无 RAG 工具调用的情况下原生具备跨会话长期记忆——这是企业场景的关键缺失能力。今日预测更新已将 P20260802-2（Alibaba 生产级长期记忆模型）概率从 0.5 上调至 0.58。
- **Code/Demo:** pending
- **信号强度：** strong

### ODEWorld: A Continuous Predictive Architecture via Physical-Time Flow
- **Authors / Lab:** UC Berkeley / Dongxiu Liu 等
- **Source:** Hugging Face Daily Papers / arXiv 2607.27924
- **核心贡献：** 提出 PT-Flow，通过 ODE 对潜空间速度场建模，实现物理时间连续的世界模型预测，突破传统离散时间步限制。
- **技术意义：** 对具身智能和自动驾驶的物理动态建模有潜在影响，代码开源。
- **Code/Demo:** available
- **信号强度：** strong

### Orchard: An open framework for scalable agentic AI
- **Authors / Lab:** Microsoft Research
- **Source:** Microsoft Research Blog
- **核心贡献：** 提供开源 AI Agent 训练与评估基础设施，支持跨任务类型复用，降低小模型构建 agent 的复杂度。
- **技术意义：** 可直接作为 agent benchmark 标准化工具使用；与 DSPy、TRL 等形成竞争。
