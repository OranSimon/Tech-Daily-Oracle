## 3. Top Developments

### 1) Nvidia 董事会调查黄仁勋“间谍门”，治理风险进入定价阶段
- **核心事实 / 关键证据**：董事会就 CEO 与 Alice Huang（Megaspeed 高管，美方情报据报认定为疑似中国间谍）的关系启动独立调查；黄仁勋向全员发备忘录承认婚外情；股价跌逾 4%；证券集体诉讼启动并有多家律所征集原告；做空机构 Culper Research 六个月前已点出该关系（强化“重大性/披露”论点）；黄仁勋退出 ElevenLabs 峰会与 Anthropic 活动。HN 该帖 947 分、1,219 条评论。
- **我的判断**：这是 key-person 与治理风险，不是基本面事件——需求、供给、路线图均无变化报道。真正的传导路径是**中国**：黄仁勋个人主导的对华出口限制游说现在在政治上“有毒”，任何放松管制的窗口都会被这起调查拖慢甚至关闭。对 Huawei Ascend 是又一次免费的份额加速。
- **不确定性**：中。“疑似中国间谍”定性来自匿名美国官员，主流措辞仍为 suspected/reportedly recruited；董事会调查结论未知，存在“查无实据但信息披露不当”与“确有安全问题”两种截然不同的结局。
- **Signals to monitor**：董事会调查的范围与是否披露内部结论；证券集体诉讼是否合并及是否出现披露相关裁定；国会/商务部是否因此放缓 Nvidia 对华许可沟通；是否有客户或合作伙伴公开拉开距离。

### 2) Anthropic 双发 Fable 5.2 / Mythos 5.2，AA 65 分登顶；同日 IPO 与 1.7GW 燃气轮机
- **核心事实 / 关键证据**：Claude Fable 5.2 与 Mythos 5.2 同日发布，主打 coding、reasoning、vision 提升与更快输出；Fable 5.2 在 Artificial Analysis 得 65 分，为“迄今最高”；两者登陆 Amazon Bedrock 与 Claude Platform on AWS；此外 Anthropic 承诺 34 亿美元采购 1.7GW 燃气发电（通过 OnePWR Solutions 接手 Caterpillar 订单，绕开约 6 年并网排队）；IPO 推进中出现一份短暂上线、隐含最高 693 亿美元融资的注册文件后被撤回。
- **我的判断**：Anthropic 现在做的是“三重下注”——能力领先（分数）、分发落地（Bedrock）、自建电力（绕开电网瓶颈）。这三件事同时发生说明它把 IPO 前的窗口当作“一次性把基础设施与叙事都锁死”的机会。撤回的文件是自伤，但也侧面确认了规模量级。
- **不确定性**：中。AA 65 分是单指数，需 Chatbot Arena / SWE-bench 等交叉验证；IPO 估值区间与时间表仍在变动（此前报道区间从 1.1 万亿到 1.5 万亿美元）。
- **Signals to monitor**：Fable 5.2 在 Arena 与 SWE-bench 的独立复现；高盛之外是否有第二家头部金融机构撤下 Claude Code；公开 S-1 是否按时提交；燃气轮机项目的并网与排放许可进展。

### 3) 高盛撤下 Claude Code + Claude Code 密钥泄露：企业信任赤字的具名化
- **核心事实 / 关键证据**：高盛据报将 Claude Code 从银行家与交易员处撤下；Apiiro 类披露称 Claude Code 的 settings 文件（“Don't ask again”类权限行为）导致 1,122 个公开 GitHub 文件暴露密码与 API key。两件事同日出现在企业采购与安全两个维度。
- **我的判断**：金融业是 agentic coding 的最高价值客户，也是最不能容忍“默认权限外溢”的客户。这次撤退的**原因未被披露**（可能是成本、合规、或内部偏好），因此不能直接归因为 token 成本或安全事件——但方向已经明确：agent 工具的采购决策正在从“能力评估”转向“权限与审计评估”。
- **不确定性**：中。撤退原因未公开；泄露规模与影响面来自第三方安全研究，未见 Anthropic 系统回应。
- **Signals to monitor**：是否有第二家 top-50 银行公开限制 coding agent；Anthropic 是否发布 Claude Code 权限/密钥处理的正式文档更新；EU DPA 或州 AG 是否就此立案。

### 4) Agent 数据边界同日双爆：Gemini 个人文件转人工标注 + ChatGPT Desktop SSH 转发
- **核心事实 / 关键证据**：（a）HN 451 分帖指控 Gemini 将个人 Drive 文件与邮件路由给人工标注员，单一来源、未获 Google 回应；（b）HN 206 分帖称 ChatGPT Desktop 将本地 SSH agent 转发至远程机器，远程 agent 可用本地凭据认证并推送到私有仓库，附 openai/codex PR #28131 讨论链接作为证据。
- **我的判断**：前者如果成立，是 GDPR/CCPA 级别的数据治理问题，打击的是 Google 最想变现的高 ARPU 订阅群体；后者即使只是“设计特性”，也意味着把开发者本地身份交给了模型执行链——这是供应链入口，不是便利功能。两条合起来说明：**agent 的价值主张（代为操作）与安全模型（最小权限）在同一天被两家头部公司同时违反**。
- **不确定性**：Gemini 一项置信度低（单一社交来源）；SSH 转发置信度中高（有可复现证据链，但 OpenAI 未就默认行为与关闭方式给出清晰说明）。
- **Signals to monitor**：Google 是否发布 Gemini 数据处理澄清或隐私政策更新；OpenAI 是否在 changelog 中加入 SSH 转发的开关/默认关闭；是否有企业公开以数据边界为由禁用相关功能。

### 5) 算力分发层的“多模型中立聚合”继续加固
- **核心事实 / 关键证据**：AWS 一周内完成 OpenAI（ChatGPT Enterprise 上 Marketplace）、Anthropic（Fable/Mythos 5.2 上 Bedrock）、NVIDIA（Nemotron 3.5 Super VL 120B 上 SageMaker JumpStart，提供 NVFP4/BF16 变体）三家同日/同周上架；Amazon Quick 更名 AWS Quick 并纳入 AWS 品牌。NVIDIA 侧则发布面向韩国四大开源模型的 Dynamo 优化部署配方。
- **我的判断**：AWS 的商业逻辑是“无论哪个实验室赢，我都收分发费”——把模型竞争转化为 Bedrock/Marketplace 的吞吐量；NVIDIA 的逻辑是“无论哪个模型赢，只要跑在我的推理栈上”。两者都在把“模型层”商品化，价值向分发与运行时迁移。这与过去两周“token 单价崩塌、企业支出停滞”的主线完全一致。
- **不确定性**：低（均为一手官方公告）；但均为厂商自述，无独立基准或客户量化数据。
- **Signals to monitor**：AWS 下一季是否披露 AI 相关收入/积压订单；Bedrock 模型目录的扩张速度；Dynamo 在韩国以外市场的采用。

- **Developer Tools / Open Source: fragmented** — 平台发布（Control Room、Bedrock）与安全事件（Claude Code secrets、SSH 转发）同日出现，缺少统一主线；无单一主导开源发布。

- **Semiconductors: fragmented** — Nvidia 治理/间谍调查主导情绪，同时出口管制、GPU 租赁上限、Megaspeed 走私调查、Huawei“全中国”PC 交织，板块缺乏单一方向。

## 6. Papers & Research Frontiers

### AutoCompress: Automated Hardware-Guided Model Compression
- **Authors / Lab:** Sheldon Liang, Ali Taghibakhshi, Saurav Muralidharan, Sharath Turuvekere Sreenivas, Ashwath Aithal, Pavlo Molchanov, Nima Tajbakhsh / NVIDIA Research
- **Source:** arXiv 2611.08290（HuggingFace Daily）
- **核心贡献:** 把 LLM 剪枝从“追参数规模”改为“面向真实 serving 负载的硬件约束搜索”（latency/throughput/显存）。
- **技术意义:** 直击“参数数量无法预测实际性能”的部署痛点，可能降低推理成本；但摘要截断，缺少压缩率与精度-延迟权衡数据。
- **Code/Demo:** 未公开
- **信号强度:** medium

### SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization
- **Authors / Lab:** Qile Jiang, George Em Karniadakis / Brown University
- **Source:** arXiv 2611.08483（HuggingFace Daily）
- **核心贡献:** 用数百个低成本 agent 在 latent space 内推理（而非长文本 CoT）来维持种群多样性，降低 LLM 引导进化搜索的延迟与成本。
- **技术意义:** 若精度与效率能兼得，会改变自动程序搜索/AI for Science 的架构经济学；Karniadakis 在科学计算领域的信誉提高了关注价值。
- **Code/Demo:** 未公开
- **信号强度:** medium（强叙事、弱可验证）

### EvoWorld: Towards Out-of-Sight World Evolution in Generative Video Models
- **Authors / Lab:** Yequan Bie, Dengyang Jiang, Zhixuan Chen, Xiaozhuan Liang, Haoxuan Che, Quande Liu, Xi Chen, Hao Chen
- **Source:** arXiv 2611.06748（HuggingFace Daily）
- **核心贡献:** 要求生成式视频模型不仅渲染像素，还要推断“视线外”事件的后果与实体状态变化。
- **技术意义:** 把 video world model 的评价从视觉逼真度转向因果一致性，对仿真、机器人、交互式内容都有意义；但无代码、无 baseline 细节。
- **Code/Demo:** 未公开
- **信号强度:** medium

### Sketchpad: certified exact arithmetic with a small vision-language model
- **Authors / Lab:** Mostafa 'Neo' Mohsenvand
- **Source:** arXiv 2611.04434（HuggingFace Daily）
- **核心贡献:** 通过把每一步限制在对外部工作记忆的有界视野内，使小 VLM 的算术精确性成为可检查的有限性质（Qwen3.5-0.8B + LoRA 在渲染画板上执行）。
- **技术意义:** 若成立，是“无需外部计算器的可验证算术”的新范式，尤其适配端侧/小模型；但单作者、机构未知、“certified”依赖未说明的形式化假设。
- **Code/Demo:** 未公开
- **信号强度:** medium
