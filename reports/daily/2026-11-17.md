### 5) 评测正在系统性失效——这比 552B 参数更重要

**核心事实 / 关键证据**
- **Correct Labels Are Not Enough（arXiv 2611.04395）**：三个家族 7–9B 开源模型微调，训练集中 metadata（如 `Reward: 5`）始终标记正确选项，**所有标签都正确**；测试时把该标记移到错误选项，模型在 CommonsenseQA 上 **97–100% 选错**，移除标记后行为恢复。
- **DominoBench（arXiv 2611.20385）**：30 个模型、10 个家族，从静态图像预测多步物理连锁结果，**无一可靠**。
- **SWE-CoWork（arXiv 2611.20218）**：101 个任务 / 101 个真实仓库 / 11 种语言 / 12 个应用领域，配 26 位权限与知识边界不同的模拟同事，测"数字员工"式协作。
- **SciResearch-Eval（arXiv 2611.21541）**：agent 自设实验，面对**故意欠分辨或物理错误**的模拟器，须报告 95% 区间。
- 反向的正面证据：**weight-space programming 复现**（arXiv 2611.21449）——三天冲刺复现 GPT-6 Astra 直写小网络权重，Breakout 得分 514/550/307（MIT 原为 517），并在两个修改版本上同样有效。这是今天**唯一被独立复现**的前沿能力主张。

**我的判断**
把今天这批论文放在一起看，结论不是"模型又强了"，而是**"我们用来衡量模型的方法正在同时从三个方向漏水"**：①标签正确但 metadata 泄漏可以让模型学到捷径，且失效是 97% 级的灾难性；②多选题式的 physical/agent 能力评测在高分背后是零真实能力；③"benchmark 分数"与"在别人系统里能不能活下来"之间存在结构性鸿沟。反过来看，这也解释了为什么 AWS 今天卖的是"托管 + 可审计 + 成本可核验"而不是分数——**企业真正在买的是"不用相信你的 benchmark"**。而唯一可信的能力信号形态是"独立复现"（如 2611.21449），这也意味着复现能力本身正在成为稀缺资产。

**不确定性**
2611.04395 的 metadata 场景是受控合成设置，97–100% 未必外推到真实数据管道；DominoBench 的"无一可靠"需看具体 pass 阈值；2611.21449 是同一生态内的快速复现，不等于第三方独立验证。arXiv ID 形态异常（2611.*）需二次核验。

**Signals to monitor**：是否有独立实验室复现 metadata 捷径效应；MLPerf/学术评测是否新增"捷径鲁棒性"分项；SWE-CoWork 是否公开 leaderboard；weight-space programming 是否出现跨实验室复现。

- **Authors / Lab:** Renee Jia, Jinzhou Wu（Hugging Face Daily）
- **Source:** arXiv 2611.04395
- **核心贡献:** 证明即使训练标签全对，与答案相关的 metadata 也会被模型学成捷径；测试时操纵该 metadata 可使 7–9B 模型在 CommonsenseQA 上 97–100% 选错。
- **技术意义:** 直接击穿"correct labels are enough"的数据质量假设，意味着 fine-tuning 管道必须检测并随机化/移除 label-correlated metadata——这是数据工程而非模型问题，落地成本低、影响面大。

### DominoBench: Evaluating Multi-Step Physical Reasoning from Still Images
- **Authors / Lab:** Emilio Ferrara
- **Source:** arXiv 2611.20385
- **核心贡献:** 用静态图像的连锁物理场景（斜坡、悬垂、摆、跷跷板、多米诺）测试 30 个模型/10 个家族，结论是没有模型能可靠预测结果。
