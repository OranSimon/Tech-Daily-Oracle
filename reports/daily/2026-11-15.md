### 5) Agent Production Plumbing: Three Papers, One Bottleneck — Plus a Viral Demo
**核心事实 / 关键证据**
- SparseRead（Anthropic 关联作者）：一个可复用的"读取控制层"，用 Read Intent Protocol 跟踪需求演化与来源覆盖，自适应选择证据粒度，在不改模型的前提下降低 token 与延迟。
- SteerDistill（Nvidia）：低比特量化让 Agent 忽略任务要求与环境条件、产生偏离全精度轨迹的环境转移；用 teacher 在 student 自身失败语境中闭环纠偏后再蒸馏。代码未公开。
- ScrapeBench：首个针对网页抓取 Agent 的 ToS/robots.txt 法律合规基准，报告多数闭源与开源 Agent 合规率低于 5%。
- HN：Claude Code + Codex 通过一枚 3 美元 Arduino 逆向 1994 年 Jeep 的 ECU（322 分 / 160 评论）。

**我的判断**
能力侧与生产侧今天被明确拉开：demo 证明 Agent 能做真实世界的硬活；论文则指出真部署时真正卡住你的是 token 成本、量化导致的行为漂移、以及合同/法律合规——**这三项没有一个出现在主流 benchmark 里**。其中 ScrapeBench 的 <5% 最具行动价值：对任何上线面向公网 Agent 的公司，这是潜伏的法律负债，我预计"Agent 合规层"会在 2027 年成为独立产品品类，路径类似 2025–26 年的 prompt injection 防护。

**不确定性**
SparseRead/SteerDistill 摘要截断、无代码、无独立复现；ScrapeBench 的 5% 高度依赖站点选择与 prompt 设置；Jeep demo 属单点轶事。

**Signals to monitor**
- vLLM/SGLang/TensorRT-LLM 是否合并"训练-推理失配"或 teacher-steering 量化特性
- 是否有 Agent 厂商发布 ToS/robots 合规开关
- 独立复现 SparseRead 的 token 节省幅度

## 6. Papers & Research Frontiers

### SteerDistill: Quantizing LLM Agents via Closed-Loop Teacher Steering
- **Authors / Lab:** Genming Cui, Xiangyu Li, Zixu Hao, Xin Ding, Yunxin Liu, Ting Cao（机构未标）
- **Source:** arXiv 2611.13410 / HuggingFace Daily
- **核心贡献:** 指出量化 Agent 会忽略任务要求与环境条件、产生偏离全精度轨迹的环境转移，用 teacher 在 student 自身失败语境中闭环纠偏再蒸馏。
- **技术意义:** 直接针对"低比特降本必然损失 Agent 成功率"这一部署悖论。如果方法成立，它是把 Agent 推向低成本/端侧的关键一环——这比单纯提升 benchmark 分数更有商业价值。
- **Code/Demo:** none
- **信号强度:** medium（摘要截断、无基线对比、无代码）

### ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping
- **Authors / Lab:** Joseph Marvin Imperial, Daniel Slate, Noam Kolt（机构未标）
- **Source:** arXiv 2611.11306 / HuggingFace Daily
- **核心贡献:** 首个测量 Agent 是否遵守 ToS 与 robots.txt 的 agentic benchmark，报告多数被测 Agent 合规率低于 5%。
- **技术意义:** 把 Agent 安全评估从"内容安全"扩展到"法律与合同合规"。这是今天最可行动的一篇：任何部署公网 Agent 的公司都在承担未被计量的法律风险，而这类风险一旦被诉讼验证，就会催生合规中间件市场。
- **Code/Demo:** none
- **信号强度:** medium（结论强、但方法与 prompt 设置未公开，需独立复核）

### EgoX: Egocentric Cross-Embodiment Manipulation with Embodiment Dreaming
- **Authors / Lab:** Yaru Niu 等（CMU 及合作方，据作者归属推断）
- **Source:** arXiv 2611.16728 / HuggingFace Daily
- **核心贡献:** 通过语义对应的观测-动作模态，把人类第一人称视频、真实机器人与仿真智能体的异构演示对齐，并引入 Embodiment Dreaming 预训练。
- **技术意义:** 若真实机器人成功率经得起检验，它解决的是具身智能最贵的成本项——**每换一种形态就要重采一遍数据**。
- **Code/Demo:** available
- **信号强度:** strong（今日唯一代码可用的跨具身工作）

### Interactive Visual Gym: Evaluating Visual Interaction Models with Simulated Users
- **Authors / Lab:** Chenhao Zheng, Silvio Savarese, Ranjay Krishna, Juan Carlos Niebles 等（DeepMind 关联）
- **Source:** arXiv 2611.08286 / HuggingFace Daily
- **核心贡献:** 提出闭环评测/训练框架，同时模拟可执行任务环境与"会改变行为的用户"，补上离线回放无法反映用户反应的缺陷。
- **技术意义:** 视觉助手与具身 Agent 的评测正在从"单轮正确率"走向"交互轨迹质量"。若框架开源，可能成为该方向的评测基础设施。
