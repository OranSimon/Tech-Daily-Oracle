## 3. Top Developments

### 1. Gemini trains on subscriber chat history — no substantive opt-out（Hacker News 707 分/182 评论）

- **核心事实 / 关键证据**：个人 Google AI 订阅用户已保存的 Gemini 聊天记录可用于模型训练，除关闭聊天历史或使用临时会话外无退出选项；Google 支持文档明确警告不要输入机密信息，因为对话可能被人工审核（即便断开会话与账号的关联）。
- **我的判断**：这是今天信息量最大的单条社会信号，原因不在"训练"本身（行业普遍如此），而在目标人群与叙事错位——Google 卖的是付费订阅，却把训练数据的默认值设成了"你不反对就同意"。对一家正在把 AI 搜索强推给学校（"可跳过 Gemini，但 AI 搜索不可谈判"）的公司，这条政策同时触发隐私与信任两条线。短期不改产品，中期会招监管。
- **不确定性**：Google 可能强调数据与账号"已断开"；也确有"关闭历史"这一路径，是否算"实质 opt-out"存在解释空间。
- **Signals to monitor**：EU DPC / UK ICO / 加州 AG 是否就 Gemini 订阅者训练数据立案；Google 是否在 2027-02-05 前给出"保留历史但排除训练"的粒度控制。

### 2. Nvidia RTX Spark encrypted firmware slows Linux inference to ~35%（Hacker News 609 分/286 评论）

- **核心事实 / 关键证据**：报道称 RTX Spark 的加密固件在 Linux 上把 LLM 推理速度压到约为基线的 35%。RTX Spark 于 2026-10-28 才正式 GA，N1X 机型已通过 Microsoft Surface Laptop Ultra 与 HP/Lenovo/Asus/Dell 铺开。
- **我的判断**：时间点极差。一个定位"AI PC"的平台在发布首周就被曝本地推理被人为设限，而限制来自固件加密而非硅本身——这会被开发者解读为刻意的商业锁定。与同日 Nvidia 博客"Vera CPU 让 AI factory 的 agent 执行更快"放在一起看，Nvidia 的叙事是分裂的：对数据中心卖"加速"，对消费端设"上限"。
- **不确定性**：单一来源 + HN 讨论，尚无官方回应、无独立复测。可能存在"某些工作负载下"的限定条件。
- **Signals to monitor**：Nvidia 是否发布驱动/固件变通方案或官方说明；独立复测（llama.cpp / Ollama 基线）能否把 Linux 推理拉回 60% 以上。

### 3. OpenAI ships GPT-6 Cyber; Google ships Gemini Omni 1.2 Flash — same day, different verticals

- **核心事实 / 关键证据**：GPT-6 Cyber 定位为对齐的网络安全模型，在授权范围内发现可利用漏洞并开发修复。Gemini Omni 1.2 Flash 主打更快、更便宜、支持更长视频片段。两家均在官方渠道发布。
- **我的判断**：这是"前沿能力垂直化"的又一次推进——GPT-6 Cyber 直接对标 Anthropic 的 Project Glasswing / Claude Mythos 生态，把"安全能力"做成可采购产品；Omni Flash 则是把多模态长视频理解压进低成本档位。两者都不是 benchmark 竞赛，而是各自抢占"有权有钱的买家"（政府/安全部门 vs. 内容与媒体客户）。真正的验证点是具名客户，不是发布页。
- **不确定性**：均无第三方基准、无客户披露、无"授权范围"的具体定义。
- **Signals to monitor**：是否有具名美国联邦机构或财富 500 强宣布 GPT-6 Cyber 生产使用/付费试点；Omni Flash 是否出现在长视频理解独立排行榜前列。

### 4. Claude Code sends user email addresses to websites + Claude Personal Finance launches

- **核心事实 / 关键证据**：GitHub issue（经 HN 448 分扩散）称 Claude Code 会把用户的邮箱地址发送给其访问的网站。同日 Anthropic 上线 Claude Personal Finance，允许通过 Plaid 连接银行/卡账户并询问消费问题。
- **我的判断**：两条必须连起来读。一边让你的 coding agent 在外部网站留下身份元数据，一边让 Claude 接入你的银行账户——对一家正在 IPO 前夜、且此前已因"共享聊天被搜索引擎索引"、"Claude Code steganographic request marking"两次被质疑的公司，数据治理正在成为它最大的、也最难快速修复的软肋。Payments/Plaid 是产品扩张，但同时也是 CFPB/OCC 关注面的扩张。
- **不确定性**：邮箱外发为单一 GitHub issue，未独立复现，可能限于特定交互路径；Personal Finance 的合规框架未公开。
- **Signals to monitor**：Anthropic 是否更新 Claude Code 数据文档并在 2026-12-05 前给出修复；是否有 CFPB / 州 AG 就 Plaid 集成发出问询。

### 5. Compute geography re-sorts: India targets homegrown GPU in 2 years; Moonshot reportedly seeks 8,000+ Blackwell GPUs via European data centers

- **核心事实 / 关键证据**：印度 MeitY 秘书 S. Krishnan 称将在 Semiconductor Mission 2.0 下于约两年内自研 GPU，并推动 SHAKTI / VEGA RISC-V 处理器商业化，同时把 AI 热潮类比为 IT 业的"Y2K 级机遇"。另据报道，Moonshot 寻求在欧洲数据中心租用至少 8,000 块 Nvidia Blackwell，主要用于推理、也询价训练集群。
- **我的判断**：同一枚硬币的两面。印度在做"主权栈"，Moonshot 在找"第三国合规通道"。执行难度完全不同：印度没有商业 GPU 硅的完整记录（SHAKTI/VEGA 是学术 RISC-V 核，不是 GPU），两年出可工作 GPU 的难度极高；Moonshot 是资本与合规的博弈，落地的可能性更大。两者共同指向：算力的可获得性正按国别重新切分，而 Nvidia 短期仍是所有路径的交汇点。
- **不确定性**：印度目标高度激进，大概率滑期；Moonshot 报道为二手，且欧洲各国对第三国算力租用的监管口径未定。
- **Signals to monitor**：MeitY 是否发布 GPU 设计招标/EDA/流片伙伴；Nvidia 是否就欧洲数据中心对华关联租户出台明确合规口径。

## 6. Papers & Research Frontiers

### Formally verifying agent-written full-stack web apps with PDD Kit
- **Authors / Lab:** Microsoft Research
- **Source:** Microsoft Research Blog
- **核心贡献:** 将开发者意图转为 Verus specification，对 AI 生成的 full-stack web 代码做全输入形式化证明，不可行处回退到测试。
- **技术意义:** 触及 AI coding agent 落地的核心瓶颈——人类无法逐行审查大规模生成代码。若可扩展，会推动"verification-first"的 agent engineering 流程，让评审对象从"每一行"变成"意图与规格"。
- **Code/Demo:** pending（未见开源）
- **信号强度:** medium（blog 表述宏大，缺同行评审与可复现实验）

### ServerBench: How can your coding agents design specialized LLM serving systems?
- **Authors / Lab:** Xinrui Zhong 等（机构未明示，代码未公开）
- **Source:** arXiv cs.AI
- **核心贡献:** 提出 agentic benchmark，要求 coding agent 在 session 依赖、延迟约束、正确性与"dollars per dollar"目标下端到端设计与运维完整 LLM serving 系统。
- **技术意义:** 把 agent 评测从"写代码"扩展到系统级工程，连接 ai_agents 与 ai_infrastructure 两条主线；若开放代码与榜单，可能成为评估 agentic systems engineering 的重要基准。
- **Code/Demo:** pending
- **信号强度:** medium

### Dory1.0-4B: A Looped Normalized-GPT
- **Authors / Lab:** Maxim Fishman 等（含多名 NVIDIA Research 研究者）
- **Source:** Hugging Face Daily / arXiv 2611.03998
- **核心贡献:** 4B 参数的 looped latent-recurrent 语言模型，基于 nGPT 骨干，交错滑窗/全注意力，单 checkpoint 支持弹性推理深度。
- **技术意义:** 单一模型按算力预算动态伸缩推理深度，若效果成立，对可变计算量推理与部署成本有实际价值——这是当前"推理成本"主线下少数真正改变架构的尝试。
- **Code/Demo:** pending
- **信号强度:** medium（摘要截断，缺 benchmark 与推理成本数据）

### Multi-layer Indexer: Overlapping Selection and Attention in DeepSeek Sparse Attention
- **Authors / Lab:** Serdarcan Dilbaz 等
- **Source:** arXiv 2611.03768
- **核心贡献:** 针对 DSA 中每层 lightning indexer 的全缓存扫描瓶颈，提出跨层重叠选择与注意力计算的 multi-layer indexer，降低长上下文推理开销。
- **技术意义:** 若能在 DeepSeek-V3.2 / GLM-5 类生产模型上落地，将直接影响稀疏注意力基础设施的长上下文服务成本。
- **Code/Demo:** pending
- **信号强度:** medium（未验证是否 DeepSeek 官方，无完整实验）
