## 3. Top Developments

### Nvidia Q2 FY2027 财报：beat 与 miss 并存
- **核心事实 / 关键证据**：整体盈利超预期，但数据中心收入未达预期，抑制市场反应（Investments 报道）；RTX 5090 出现"8 主板捆绑搭售"，零售渠道 GPU 稀缺态势类似加密矿业时期（Tom's Hardware）。
- **我的判断**：这是"AI capex 无限论"第一次在财报中被现实纠偏。HBM 短缺、Rubin Ultra 减配内存传闻、出口管制全球执行三重约束，意味着供给曲线已比需求曲线更硬。对超大规模客户仍是买方市场，但对 Nvidia 而言"毛利率与供给上限"而非"需求"成为新约束。
- **不确定性**：当前事件摘要未披露中国区收入与全年指引细节，P20260515-3、P20260609-3、P20260613-6、P20260627-5、P20260628-6、P20260604-5 六条预测均待财报细分数据确认——不能仅凭"beat/miss"标题提前判定。
- **Signals to monitor**：Q2 财报电话会是否下调全财年收入指引；中国区/Hong Kong 地理收入披露；管理层对 HBM 与 Rubin Ultra 显存配置的最新口径。

### Amazon 天然气电站：AI 基建的 ESG 转折点
- **核心事实 / 关键证据**：Amazon 确认出资建设德州 Pecos County 大型天然气电站，为其 West Texas 数据中心供电，或成美国最大单体温室气体源（NYT、The Verge、SCMP，Cleanview 卫星影像交叉验证）；Gilroy 数据中心利用 45 年前旧规绕过社区公投（Tom's Hardware）。
- **我的判断**：私有电力+"离网化"已成为超大规模客户的必然动作，但 Amazon 的气候承诺与本地社区治理之间出现结构性矛盾。短期内现金流无碍，中期监管、许可与诉讼成本上升。这与 AMZN 市场信号中的"ESG 监管风险"互为印证。
- **不确定性**：电站最终碳排放量、是否加入 CCS、TCEQ/EPA 是否启动审查均未定；"最大单体排放源"来自 Cleanview/NYT 估算而非官方口径。
- **Signals to monitor**：TCEQ 空气许可抗议是否成立；EPA 或环保组织诉讼；Amazon 是否回应碳抵消承诺。

### DeepSeek V4 Flash 0731 + 昇腾 950DT 联合设计
- **核心事实 / 关键证据**：V4 Flash 0731 登 ARC Prize，HN 743 分/448 评论；DeepSeek 与华为联合设计 Ascend 950DT，宣称推理成本降低 75%（硬件主题摘要及公司分析）。
- **我的判断**：这是"软硬协同降本"路线继 DeepSeek V4 独占昇腾后的第二次确认。若 75% 成本削减被第三方验证，中国侧推理定价权将显著增强，直接压缩全球 API 价格地板；对 P20260515-1、P20260517-4、P20260606-2 等华为份额/营收预测形成同向强化。
- **不确定性**：成本数据为厂商口径，无独立复现；ARC Prize 得分不直接等于商业化能力。
- **Signals to monitor**：昇腾 950DT 在字节/阿里/腾讯的部署规模；DeepSeek API 价格是否进一步下调；国际基准第三方评测。

### AMD 收购 Taalas：模型蚀刻进硅片
- **核心事实 / 关键证据**：AMD 宣布收购 Taalas，以在芯片内硬编码 AI 模型提升推理性能（The Register / AMD IR）；HN 921 分/693 评论。
- **我的判断**：模型权重一旦"蚀刻进硅片"，推理时延与每 token 成本将大幅低于通用 GPU，但灵活性受限。AMD 借此在推理赛道建立区别于 MI 系列的差异化，也是对 Nvidia 推理 GPU 定价权的直接进攻。
- **不确定性**：技术成熟度与流片周期未知；"硬编码"路线能否兼容模型快速迭代是最大风险。
- **Signals to monitor**：AMD 是否在 12 个月内给出商业化产品路线图（已列入新预测 P20260808-4）。

### DeepMind WeatherNext 飓风预测突破
- **核心事实 / 关键证据**：开源 WeatherNext 用低分辨率数据即实现高精度气旋预报，为预报员多争取一天预警时间；天气科学家公开表示意外（Ars Technica、DeepMind blog、HN 337 分）。
- **我的判断**：这是 AI for science 少数"经过领域专家验证、可立即业务化"的案例。开源属性使其更容易被国家气象机构集成，是 AI 应用从消费/企业走向公共部门基础设施的样板。
- **不确定性**：多气候区泛化性、与 IFS/GFS 业务系统混合部署的兼容性未验证。
- **Signals to monitor**：NOAA/ECMWF/UKMO/JMA 是否进入业务试点（已列入新预测 P20260808-5）。
