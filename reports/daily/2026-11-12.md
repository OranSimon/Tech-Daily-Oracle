## 3. Top Developments

### Nvidia CEO Jensen Huang Resigns — 供应链、政策与开源三条线同时悬空
- **核心事实 / 关键证据：** 黄仁勋因婚外情（其中一段涉及被美方指认为疑似中国情报人员的女性）辞职，Nvidia 由 CFO Colette Kress 临时接任；民主党启动针对 Nvidia 对华销售及黄与特朗普往来的国会调查（此为丑闻曝光后第二项调查）；市值损失约 1 万亿美元；员工内部请愿 1,600+ 条评论要求复职；特朗普在 Truth Social 提议 Tim Cook 接任。
- **我的判断：** 市场会把这件事当成"治理事件"来交易，但它实质上是**三条资产的同时贬值**。第一，key-person 风险：黄仁勋是 Nvidia 与全球政要私人关系的支点，sovereign AI 与政府订单高度绑定个人；Kress 明确认为应允许向中国出售最先进芯片，这在美国国会正收紧审查的窗口里，等于把公司放到政策博弈的主动方位置。第二，开源承诺：Nvidia 的 $12.9B Hugging Face 收购、open-weight 模型倡导与反限制游说，全都依赖 CEO 级别的意志，临时管理层最理性的选择是"暂缓一切有争议动作"。第三，路线图信心：Rubin/Vera 的年度节奏依赖极强的执行文化，领导层真空期通常意味着产品滑期风险上升。真正的观察点不是谁接任，而是**国会调查是否把"对华销售"变成"合规负债"，从而迫使 Nvidia 自己削减中国敞口**。
- **不确定性：** 董事会是否会在短期内确认永久 CEO；国会调查的实质范围（是查黄个人，还是查 Nvidia 的出口合规流程）；Hugging Face 交易是否会被重新审视或延迟交割。
- **Signals to monitor：** ① Nvidia 8-K/Form 4 的正式高管变更披露；② 参议院 Banking / 众议院 Foreign Affairs 是否就 China sales 排期听证；③ Hugging Face 交易在监管审查中的状态变化；④ Kress 在下一场财报电话会上的中国指引措辞。

## 6. Papers & Research Frontiers

### Evolving Infra: Agent-Adaptive LLM Serving at Scale
- **Authors / Lab:** Hao Kang, Weili Xu, Ziyang Li, Zheng Du, Hanchen Li, Tian Xia, Song Bian, Tushar Krishna, Huizi Mao, Ion Stoica, Song Han（UC Berkeley / MIT / NVIDIA，作者推断）
- **Source:** arXiv（HuggingFace Daily）
- **核心贡献:** 提出 agent-adaptive 服务框架，用细粒度 agent 负载信号动态重分配 prefill/decode 算力并管理 KV cache，降低负载不均衡与缓存驱逐。
- **技术意义:** 直接命中 agentic 推理的成本结构——PD 分离 + KV cache 复用是当前 AI infra 最热的两条工程线。作者阵容（Stoica、Song Han、Tushar Krishna）意味着这是"系统性工作"而非单点 trick。若方法有效，会实质改善大规模 agent 推理的吞吐与资源利用率。
- **Code/Demo:** 未见
- **信号强度:** strong
- **Caveat:** 摘要截断，无实验数据；arXiv ID 格式（2611.12304）需核实；机构为推断。

### Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents
- **Authors / Lab:** Yukyeong Lee, Yumin Choi, Jinheon Baek, Sung Ju Hwang（KAIST，推断）
- **Source:** arXiv（HuggingFace Daily）
- **核心贡献:** 提出 evidence-linked external memory——把每条提炼出的"经验"绑定到它来源的轨迹证据上，让 agent 在复用前可校验，从而减少 memory-induced degradation。
- **技术意义:** 这是 agent memory 领域少见地正面处理"记忆反而拖累性能"这一失败模式的工作。把 provenance 引入 memory 检索，对任何做持久化 agent memory 的框架都有直接工程价值（LangChain/LlamaIndex 类工具的条件是明摆着的）。
- **Code/Demo:** 报告称有 code
- **信号强度:** strong
- **Caveat:** 摘要截断，无量化结果；机构推断。

### ScrapeBench: Evaluating Legal Compliance of AI Agents in Website Scraping
- **Authors / Lab:** Joseph Marvin Imperial, Daniel Slate, Noam Kolt
- **Source:** arXiv（HuggingFace Daily）
- **核心贡献:** 首个系统评测 web agent 是否遵守 ToS 与 robots.txt 的 agentic 基准，发现主流闭源与开源 agent 的合规率普遍 **低于 5%**。
- **技术意义:** 它把"agent 合规"从抽象讨论变成可量化指标。Noam Kolt 长期研究 AI 与法律治理，这让该基准在治理话题上有话语权。对任何在生产里跑 web agent 或爬虫管线的团队，这是一个直接可用的风险度量工具——也是监管介入时最可能被引用的证据。
- **Code/Demo:** 未确认
- **信号强度:** medium（结论方向明确、负面，炒作空间低）
- **Caveat:** "合规率"定义、prompt 设计、不同司法辖区适用性均有争议。

### LEASH: Stay Safe in Agentic Robotics（含 RoboRisk 基准）
- **Authors / Lab:** Qinfeng Zhu, Weiguang Zhao, Ke Sun, Xihao Guo, Yunxi Jiang, Rui Zhang, Lei Fan, Kaizhu Huang
- **Source:** arXiv（HuggingFace Daily）
- **核心贡献:** 提出 RoboRisk——针对 foundation model 控制机器人时安全风险的系统评测基准，覆盖 92 个模拟任务与多类物理/风险场景。
- **技术意义:** 切中 embodied AI 从"能力展示"走向"真实部署"时最关键的 safety evaluation 缺口。若开源并被社区采用，可能成为 agentic robotics 的安全测试参考。
- **Code/Demo:** 未见
- **信号强度:** medium
- **Caveat:** 无 code/demo 链接；有无真实机器人验证未知。

*（另有 SteerDistill、Sable、Interactive Visual Gym、PhyRubric 等，今日研究前沿整体偏"agent 效率与安全"，密度高但多为单点方法，不逐一展开。）*
