**我的判断**
这是本轮 AI 周期首次出现"最重要公司的单点故障"被公开定价。三个层次必须分开看：

3. **合规层**：空壳公司事件打击的是 H200 许可通道本身的合法性。它与 CEO 调查没有因果，但共享同一个政治后果——BIS 收紧或撤销部分许可的成本大幅下降，因为国会现在有了"必须做点什么"的现成理由。

**我的判断**
把这两半放在一起看才有信息量：**算力侧在加速买稀缺资产，分发侧在失去默认值。** 34 亿美元的电力采购说明 Anthropic 判断约束在能源与设备，而不是需求；但企业侧的撤下说明它的工具还没通过"金融级合规"这道门。二者的共同点是都指向 IPO 前的估值叙事——一边证明"我能拿到别人拿不到的电"，一边暴露"我的 agent 默认值不满足受监管行业的审计要求"。

我认为高盛这条的**方向比细节更重要**：无论最终是安全审查未通过还是成本/ROI 重估，一家投行把已部署的工具收回，意味着企业采购的门槛从"能力"变成了"可审计性"。这与本周主线（信任成为定价项）完全吻合。

**不确定性**

- 34 亿美元是设备采购额还是含运维的总承诺，报道口径不一。

### 3) DeepSeek：154 万日活的 agent 平台 + 284B 模型跑在 64GB 内存

**核心事实 / 关键证据**
- Bloomberg 报道 DeepSeek AI Agent 平台日活达 154 万，被明确定位为对 OpenAI/Anthropic 的竞争压力（厂商口径，无独立审计）。
- HN：llama-modchip 项目演示 284B 参数 DeepSeek 模型在 64GB 内存、无 GPU 条件下推理（348 分/145 评论）。
- arXiv 2611.03768 分析 DeepSeek Sparse Attention 的多层 indexer，指出长上下文下的真实瓶颈是逐层 lightning indexer 的 KV 扫描，而非稀疏注意力本身。
- deepseek-harness 开源（"一切皆插件"的 agent 开发脚手架）。

**我的判断**
这是今日中国侧最强的一组信号，因为它同时覆盖了**采用（日活）、技术影响力（DSA 被外部论文当作参考架构）、生态（开源 harness）、以及成本创新（CPU-only 推理）**。但四个证据的强度差异极大：
- 154 万日活是唯一无法验证的一项——它是厂商口径、二手转述，且"日活"在 agent 平台语境下可能包含免费额度、API 沙箱或自动化流量。
- llama-modchip 是真实的技术演示，但 284B 跑在 64GB 内存必然依赖激进量化与 offload，**其质量与速度不代表生产保真度**。把它当作"前沿模型可在消费硬件运行"的证据是合理的，当作"DeepSeek 推理成本极低"的证据则是过度外推。
- DSA 论文反而是最有信息量的一条：它说明 DeepSeek 的架构已经外溢为学术参考标准，同时也暴露了它真实的长上下文成本结构。

**不确定性**
- 日活数字无审计，且未区分应用层与 API 层。
- CPU 演示无第三方基准复现。
- 论文摘要被截断，且 arXiv ID 与当前日期不一致（2611.03768），存在元数据问题。
- 中美出口管制与实体清单风险可能随时改变其可服务市场（P20260618-3 仍在跟踪）。

**Signals to monitor**
- 是否有 Sensor Tower/SimilarWeb 类第三方给出可比的 DeepSeek agent 平台用量估计。
- deepseek-harness 的 GitHub star 增速与外部框架集成情况。
- DSA 多层 indexer 是否被 DeepSeek-V3.2 或 GLM-5 系列在生产模型中验证。

### 4) Apple：Siri agent 化被证实"在赶"，隐私信誉同时在流失

**核心事实 / 关键证据**
- Bloomberg（Gurman）：CEO John Ternus 正向 AI 负责人 Craig Federighi 施压压缩 Siri 路线图，目标是把 Siri 从语音助手改造为对标 OpenAI Dots 与 Meta Muse 的自主 agent，指向 iOS 28 周期；当前交付的 Siri AI 被视为"功能版本"而非竞争版本。
- iOS 27.3 beta 代码出现 "Conversational Apps" 分类标记，暗示 HomeView 智能家居中枢可能开放接入第三方聊天机器人（ChatGPT/Claude 类）。
- HN：iPhone 拼写检查"灰名单"（526 分）与 Mac 上未文档化的"家庭成员分类器"（844 分）——两条都是隐私/透明度争议。
- 财务/税务侧：新加坡已取代爱尔兰成为 Apple 最大税务庇护地，通过利润分配实现约 27 亿美元税负节省。

**我的判断**
Apple 今天的信号全在"未来时态"——爆料、beta 代码 flag、路线图压力。这类信号的价值不在于"Apple 要做 agent"，而在于**它承认自己落后**：CEO 层直接向软件负责人施压，是内部判断"现有交付不具备竞争力"的最强证据。

更值得注意的是 HomeView 的 "Conversational Apps"：如果它落地，Apple 会在自己的硬件上成为一个**第三方 AI 的分发渠道**，而 Siri 则要与这些被自己引入的助手竞争默认权。这是战略性大于产品性的动作，也是我在今日最愿意给"值得跟踪"标记的一条。

隐私两条帖子的共同点是"系统在本地做推断但不告诉你"——灰名单（内容取舍）、家庭关系分类器（个人信息图谱）。它们不会立刻变成诉讼，但会积累成 DMA/GDPR 层面的问询素材。

**不确定性**
- Siri agent 的一切都停留在爆料与路线图层，无 demo、无时间承诺、无基准。
- HomeView 集成仅是 beta 代码中的一个 flag，可能被移除。
- 新加坡税务结构是已发生事实，但监管跟进的时间与形式未知。

**Signals to monitor**
- WWDC 2027 是否出现 agentic Siri 的实机演示（而非概念视频）。
- "Conversational Apps" 是否在正式版 iOS 中保留并开放给第三方。
- 是否有 EU DPA 就"本地推断 + 无披露"启动问询。

## 6. Papers & Research Frontiers

### Ask, Don't Equip: Question-Driven Coding Agents for Deep Kernel Optimization
- **Authors / Lab:** Gabriele Oliaro, Jaeseong Lee, Zhaoyuan Su, Sreeram Vennam, Zhihao Jia, Samyam Rajbhandari（CMU / Microsoft Research，未核实）
- **Source:** HuggingFace Daily / arXiv 2611.03517
- **核心贡献:** 提出"提问驱动"的 coding agent 范式，用问答在脚本化 agent（样本效率高）与开放式 kernel 变异 agent（灵活）之间取平衡，用于 GPU kernel 优化。
- **技术意义:** 若成立，可降低 LLM 驱动的 GPU kernel 调优成本，直接对应 AI infra 团队的自动化性能工程——这是"agent 进入生产系统"最可验证的一条路径。
- **Code/Demo:** none
- **信号强度:** medium（作者阵容强、主题热，但摘要截断，无基准、无代码、无相对 SOTA 的提升幅度）

### Multi-layer Indexer: Overlapping Selection and Attention in DeepSeek Sparse Attention
- **Authors / Lab:** Serdarcan Dilbaz, Arjun Krishna, Kiran Kamble, Daniel M. Bikel（机构未知）
- **Source:** HuggingFace Daily / arXiv 2611.03768
- **核心贡献:** 针对 DSA 中逐层 lightning indexer 在长上下文成为瓶颈的问题，提出跨层重叠/共享 token 选择以降低扫描开销。
- **技术意义:** 这是今日最具**生产相关性**的论文——DSA 已被 DeepSeek-V3.2 与 GLM-5 家族采用，若该方法在真实模型上验证有效，将直接影响长上下文推理的成本与吞吐。
- **Code/Demo:** none
- **信号强度:** medium（问题定义清晰、直指生产瓶颈；但无基准、无代码，且 arXiv ID 与当前日期不一致，需核实元数据）

### The SIMPLE Law for Energy Cost of LLM Inference
- **Authors / Lab:** Hiari Pizzini Cavagna, Andrea Proia, Daniele Cesarini, Zeynep Kiziltan, Andrea Bartolini（机构未知）
- **Source:** HuggingFace Daily / arXiv 2611.03330
- **核心贡献:** 推导 LLM 推理的计算与访存复杂度闭式表达，显式建模 KV-cache 增长导致的"后段 token 更贵"，并声称无需对每个模型单独拟合系数。
- **技术意义:** 若可泛化，将进入推理服务的容量规划、token 定价与能耗核算。它与今日 Anthropic 34 亿美元电力采购形成互文：**能耗正从运维指标变成财务科目**。
- **Code/Demo:** none
- **信号强度:** medium（标题使用 "Law" 属强表述，但缺代码与跨架构/跨硬件验证）

### SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization
- **Authors / Lab:** Qile Jiang, George Em Karniadakis（Brown University）
- **Source:** HuggingFace Daily / arXiv 2611.08483
- **核心贡献:** 用每轮数百个低成本 agent 在潜空间推理并演化候选程序，避免重复生成长文本 CoT，同时维持种群多样性。
- **技术意义:** 若能降低 LLM 引导进化搜索的延迟与成本，对科学计算与数学优化工作流有直接价值；Karniadakis 在科学计算/PINN 领域的影响力提升了它的可信度。
- **Code/Demo:** none
- **信号强度:** medium（无定量结果、无与传统方法的速度/质量对比）

> 今日论文整体：数量密集（23 篇以上），方向分散（agent、推理加速、具身、评测基准）。共同缺陷是**摘要普遍截断、代码普遍缺失**——这意味着"高论文量"本身不构成趋势证据，只能构成"研究者注意力分布"的证据。
