## 6. Papers & Research Frontiers

### OSWorld 2.0: Benchmarking Computer Use Agents on Long-Horizon Real-World Tasks
- **Authors / Lab:** 36 位研究员联署（Alibaba/Tongyi、McGill、UCSC、哥伦比亚等多机构）
- **Source:** Hugging Face Daily Papers / arXiv 2606.29537
- **核心贡献:** 108 个长任务 computer-use 基准（每任务人类完成中位时间约 1.6 小时），是现有 computer-use 基准复杂度的数量级跨越。
- **技术意义:** 直接暴露当前前沿 Agent（Claude Computer Use、GPT-4o 等）在真实长任务中的深层能力缺口，将成为 Claude Sonnet 5 和 Gemini Omni Flash 等新模型的核心压力测试基准。对 Agent 产品团队的工程路线图有直接指导价值。
- **Code/Demo:** 待确认
- **信号强度:** strong

### SkillOpt: Agent Skills as Trainable Parameters
- **Authors / Lab:** Microsoft Research
- **Source:** Microsoft Research Blog
- **核心贡献:** 将 AI Agent 的 Skill 指令（prompt）视为可训练参数，通过优化过程自动改善 Agent 行为，无需修改模型权重。
- **技术意义:** 与 DSPy、TextGrad 同一思路，但专注 Agent Skill 层系统化训练，解决手动调整 Agent 指令效率低的工程痛点。如果 6-12 个月内进入 Copilot 产品，对企业 AI 工作流定制有实质影响。
- **Code/Demo:** 仅博客，无代码
- **信号强度:** medium

### MESA: Prioritizing Vulnerable Communication Channels for Securing Multi-Agent Systems
- **Authors / Lab:** Kunyang Li, Kyle Domico, Jonathan Gregory, Patrick McDaniel（arXiv 2606.30602）
- **Source:** arXiv cs.AI
- **核心贡献:** 首次将多智能体系统（MAS）的通信渠道攻击面进行系统性优先级排序，揭示渠道级攻击影响高度非均匀，为防御资源分配提供理论框架。
- **技术意义:** 随着企业级 MAS 部署加速，多 Agent 安全已从边缘议题变成产品合规前提。此类研究预计将在 1-2 年内影响 Agent 安全合规标准。
- **Code/Demo:** none
- **信号强度:** medium

### Agentic Abstention: Do Agents Know When to Stop Instead of Act?
- **Authors / Lab:** Han Luo, Bingbing Wen, Lucy Lu Wang
- **Source:** Hugging Face Daily Papers / arXiv 2606.28733
- **核心贡献:** 首次系统定义并评测"Agentic Abstention"问题——LLM Agent 是否能正确识别目标不可达或环境不足时停止行动。
- **技术意义:** 这是一个被广泛忽视的基础可靠性问题。企业部署 Agent 的核心顾虑之一正是 Agent 在不确定情况下不断尝试而非请求人工干预。解决此问题是 Agent 进入受监管场景的必要条件。
- **Code/Demo:** 有（分类标签标注）
- **信号强度:** medium
