## 4. 本周论文与研究前沿

1. **Qwen-CUA（397B MoE，原生电脑操作 Agent）**
   - 仅靠截图+键鼠操作电脑，不依赖 DOM/API。这是"通用计算机操作 Agent"从 demo 走向 scale 的重要证据。阿里在 agentic 技术栈（训练-推理-检索）全线卡位。
   
2. **Alibaba：Memory Decoder at Scale**
   - 将参数化长时记忆模块扩展到 6.9B 参数、300B tokens，直接推进 P20260802-2（Qwen 生产模型采用记忆模块概率升至 58%）。若走向生产部署，是对 context window 路线的补充性挑战。

3. **Meta：Fairness Pruning**
   - 用 minimally contrastive prompt pairs 和 differential activations 定位 GLU-MLP 层的 demographic bias。研究动量直接对应 P20260802-3，但目前仅限 bias localization，尚未做 10B+ 生产模型的 20% bias 削减验证。

4. **Meta：GEM（Generative Ads Recommendation Model）**
   - 在数千块 Nvidia 最新 GPU 上实现 E2E 训练 20-25% MFU，训练 FLOPs 扩展 4 倍。这是工业级大规模推荐系统首次展示可复现的优化文档；也间接确认 Nvidia 硬件在 AI 广告核心系统中的不可替代性。

5. **HuggingFace 本周新论文集群：Recursive Synthesis、FinanceHarness、AI Red-Team Evaluations、SIGNPOST-Bench**
   - 覆盖方向：递归合成训练数据、金融深度研究 Agent、红队测试证据边界、多模态冲突消解。Agentic 评测和安全评估正在成为独立研究前沿，与本周"安全成为硬成本"主线一致。

**研究动量判断**：最热方向是 Agentic 评测与训练基础设施效率；最大惊喜是阿里在同一天内同时输出模型、Agent、量化、KV cache 四类论文，显示体系化研发能力。

## 13. 错误类型分析

- **Over-weighting hype signals（过度加权热度信号）**
  - 案例：Qwen3.8-Max 的 HN 高分和 Agentic Index 登顶均属"发布日信号"，独立 Chatbot Arena 排名和第三方复现尚未出现。我已在 P20260719-1 中将概率上调至 0.62，但需警惕"社区热度→能力确认"的跳跃。
  - 改进：将"发布事件"与"独立验证事件"分开建模。

- **Under-weighting official announcements（低估官方公告的确认价值）**
  - 案例：8/5 我判断 Anthropic 与 Samsung 合作"传闻尚未坐实"，8/7 即被确认为 manufacturing partner。连续两个预测（P20260702-2 0.52、P20260725-5 0.45）本可更早加强。
  - 改进：对"公司公开招聘 + 主流媒体多源报道"这类组合信号，应视为 high-confidence 前兆。

- **Incorrect time horizon（时间窗误判）**
  - 案例：Nvidia 数据中心 miss 是即时财报信号，但市场反应温和（+2.6%），说明"收入结构性下滑"的定价需要更长时间。预测层面，P20260613-6（不下修全财年指引）概率 0.30 相对合理，但市场信号的 NVDA 入场点判断需要区分"2–8 周"与"季度级"两个时间尺度。
  - 改进：在 MarketSignal 中明确"事件驱动定价"与"趋势定价"的时间差。

- **Missed signal type（遗漏信号类型）**
  - 案例："能力过强导致的自我暂停"（OpenAI Astra）是我此前未充分建模的信号类型。我一直将安全事件视为"负面风险"，但 Astra 案例表明"安全透明度"可以成为 IPO 叙事中的正面资产。
  - 改进：新增"capability-based self-pause"作为独立信号类型，纳入 P20260722-2 类联邦政策预测的输入。
