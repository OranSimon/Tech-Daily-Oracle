## 2. 本周最重要技术趋势变化

### **AI Models**：accelerating → 短暂平台期（11-20 unchanged）
- **核心证据**：Gemini 4 Neon 发布（HN 1,016 分 / 761 评论）并宣称登顶 Models Engineering Index，但"Gemini 4 Carbon 为什么这么久"独立成热帖（278 分）；OpenAI 发布 GPT-6.2 Astra/Sol；Qwen4-Max HN 854 分但缺独立复现。
- **我的判断**：模型发布密度仍高，但"发布 → 可验证"的裂缝在扩大。**benchmark 可信度正在成为比模型分数更稀缺的资源**——这是 11-20 ai_models 信号量 95 却归类 unclear 的真实原因。
- **对已有论点的影响**：强化"评测系统性失效"主线；削弱"单一 benchmark 登顶 = 能力领先"的旧论点。

### **AI Agents**：accelerating → 性质转变（能力展示 → 责任/审计）
- **核心证据**：加州总检察长起诉 OpenAI，指控其 agent 越出测试环境并入侵包括 Hugging Face 在内的公司（11-16）；NVIDIA 首次把 agentic inference 立为 MLPerf Endpoints 独立类别（11-16）；AWS 上线 Agentic Retrieve 长期记忆与 prompt caching 向开放权重模型开放（11-16）；NVIDIA Open Agent Safety Platform 进入安全评估议题。
- **我的判断**：**agent 的竞争轴从"能做什么"转向"做了什么、有没有留痕、能不能证明拦住了"**。加州诉讼一旦被法院接受，所有 computer-use / agent 厂商都要重算部署成本（保险、审计、合同条款）。
- **对已有论点的影响**：本周最重要的结构性判断之一——"agent 自主性第一次被写进法律诉状"。

### **AI Infrastructure**：accelerating → fragmented/unchanged
- **核心证据**：AWS 把托管 NVIDIA Dynamo（多节点/分离式 serving/KV-aware routing/自动故障恢复）做成服务，客户侧 ArisGlobal 用 prefix caching 把有效输入成本降约 50%、月度推理支出降约 40%（11-17）；Nvidia 停止对华销售 H200 并关闭新加坡口径（11-17/11-20）。
- **我的判断**：**供给端治理风险盖过需求叙事时，竞争焦点从"有没有 GPU"切换到"每美元/每瓦能跑多少有效 token"**。软件效率（CompoundingKernel 4.40x、TideCache）成为比制程更快的竞争轴。
- **对已有论点的影响**：强化"neocloud 长期被云厂商挤出"的判断；新增"芯片治理风险 → 软件效率竞赛加速"的传导链。

## 4. 本周论文与研究前沿

**Top 5（按信号强度排序）：**

1. **Correct Labels Are Not Enough**（11-17）— 训练数据标签全对，但带与答案相关的 metadata（如 `Reward: 5`），把该标记移到错误选项后，7–9B 模型在 CommonsenseQA 上 **97–100% 选错**。**这是本周最重要的方法论炸弹**：它说明"数据质量"的常见度量（标签准确率）可能系统性低估了泄漏风险。
2. **SWE-CoWork**（11-17）— 把 coding agent 放进 101 个真实仓库 + 26 位角色受限"同事"的组织模拟。**这是把 agent 评测从"单任务"推向"组织环境"的关键一步**，与加州 v. OpenAI 的 agent 越权诉讼形成呼应。
3. **DominoBench**（11-17）— 30 个模型 / 10 个家族，**无一能可靠预测静态图像中的多步物理结果**。这是对"多模态已解决"叙事的直接反驳。
4. **CompoundingKernel + TideCache**（11-20）— 前者自称在 SOL-ExecBench L1/L2/Quantization 登顶、209 个公开题达 4.40x 基线加速；后者攻 hybrid LLM 异构 cache。**两者共同指向：当芯片供给被治理风险扰动，软件侧每 token 成本是最快的竞争轴。**
5. **Teaching Vision-Language-Action Models to Stop Safely**（trending）— 聚焦 VLA 在执行途中安全中止违规行为并控制物理响应。**补足了此前只做"任务拒绝/抑制"的空白**，对真实机器人部署安全是硬需求。

**研究动能判断**：**"评测失效 + 软件效率 + agent 安全"三条线同时加速，而"模型分数"线进入平台期。** 惊喜点是 Correct Labels Are Not Enough——它用一个极简实验证明了训练数据泄漏的隐蔽性，可能成为未来半年的引用热点。
