## 1. 本周主线

本周的主线不是任何一次模型发布，而是**能力曲线与信任曲线在同一周被同时定价，并且定价方向相反**。

时间线清晰：11-09 Nvidia 董事会就黄仁勋与一名被美方标记为疑似中国情报人员的女性的关系启动独立调查，股价跌逾 4%，证券集体诉讼启动；11-12 黄仁勋辞去总裁、CEO、董事职务，CFO Colette Kress 任临时 CEO，同一周董事会据报接触 Arm CEO Rene Haas，约 1 万亿美元市值蒸发；11-13 走私估算与第三国执法叠加——约 1.5GW 被禁加速器入华、马来西亚调查再出口、新加坡就 917 台 AI 服务器采购起诉一名高管、$11.4M Nvidia 硬件在加州—德州运输途中失踪。

而能力侧同周照常推进，且质量不低：11-09 Claude Fable 5.2 拿下 Artificial Analysis 65 分（历史最高），Mythos 5.2 同日上 Bedrock；11-12 Gemini 4 Hydrogen 连同 Antigravity Orchestrator 发布并**同日**进入 Search AI Mode、Gemini app 与全部订阅层级；11-13 OpenAI 用 ChatGPT Wallet 让 agent 第一次获得"花钱权"。

信任侧的负向同样密集：11-12 Microsoft 365 近 24 小时全球中断（HN 1,161 分 / 977 评论，医院、法院、学校、财报发布受实质影响）；11-09 高盛据报将 Claude Code 从银行家与交易员处撤下，同日 Claude Code settings 文件在 GitHub 泄露大量密码与 API key；ChatGPT Desktop 把本地 SSH agent 转发给远程机器（有 codex PR 证据）；Gemini 被指控将个人 Drive 文件与邮件转给人工标注员（单源、未验证）。

**本周将被记住的方式**：不是"AI 又变强了"，而是"AI 的合规与控制基础设施第一次成为比模型分数更紧的约束"。技术上没有坏消息；制度上有。这两个判断同时为真，且它们之间的价差第一次被资本市场、企业与监管三方在同一周分别定价。

## 2. 本周最重要技术趋势变化

### Semiconductors：fragmented → **reversing**（11-13，29 条信号，strong_trend）
- **核心证据**：黄仁勋辞任；约 1.5GW 被禁加速器入华（SemiAnalysis 类单点估算，未经官方确认）；马来西亚调查再出口、新加坡起诉一名高管（917 台 AI 服务器）；$11.4M 硬件运输失踪；Nvidia 在 229 家私营公司约 $48B 的投资组合成为治理议题；国会调查已启动。
- **我的判断**：`reversing` 不是需求反转，是**叙事范式反转**——从"算力永远供不应求"切换到"算力供应链是一个政治许可问题"。本周没有任何需求侧的负面数据，Nvidia 的产品路线（Vera Rubin 爬坡）也没有被报道受影响。真正的反转是：护城河的构成从"技术 + 产能 + 游说"变成"技术 + 产能 + 政治上是否愿意继续给例外"。
- **对已有论点的影响**：Nvidia 中国区收入应被视为**结构性折价**而非周期性波动。此前"管制收紧 → 中国收入下降 → 但被 hyperscaler capex 补足"的框架仍成立，但漏掉了一项：合规成本从"许可审批"升级为"刑事与民事诉讼"，这会抬高每一笔非美国销售的边际成本，且不可通过降价对冲。

### AI Agents：accelerating（11-09 / 11-12 / 11-13，17–20 条，strong_trend）
- **核心证据**：ChatGPT Wallet 面向美国 Pro 用户开放，覆盖 ChatGPT Work / Codex / Dots，机制为"用户批准 + 现有卡组织保护"；AWS 扩容 Bedrock AgentCore 并出现具名生产案例 Natera SWARM（首响约 130 倍加速、96.2% 自动化工单覆盖）；Gemini 4 Hydrogen 配 Antigravity Orchestrator。反向证据：ChatGPT Desktop SSH agent 转发、Claude Code settings 泄密。
- **我的判断**：本周 agent 的边界同时跨了两道——从"信息动作"跨到"资金动作"，从"单 agent"跨到"编排层"。但**加速的是商业化路径，不是可靠性**。OpenAI 的设计（审批权留给人、风控责任留给卡组织）非常聪明地外化了风险，代价是当 agent 发起的交易产生争议（误购、提示注入诱导购买、订阅陷阱）时，chargeback 归责规则并不存在。
- **对已有论点的影响**：agent 的瓶颈已从"能不能做"转为"谁承担做错的责任"。这会让 2027 年的合规采购问询单比任何能力榜单更早决定份额。

### AI Infrastructure：accelerating → **fragmented**（11-13，30 条，strong_trend）
- **核心证据**：Anthropic 承诺 34 亿美元采购 1.7GW 燃气发电（借 OnePWR 接手 Caterpillar 订单，绕开约 6 年并网排队）；其算力供应商 Nscale 警告需追加融资才能履约；Nebius $40B 计划明确提到微软数据中心延期；微软据报重新评估 Nscale / IREN / Nebius 的新云交易。
- **我的判断**：这是"accelerating 但质量下降"的典型形态——扩张在继续，但**融资结构脆弱性与物理延期第一次落在同一个新闻周期**。此前市场把 AI capex 的约束理解为"有没有电"；本周的约束变成"有没有人愿意为 6 年后的电付钱"。
- **对已有论点的影响**：Anthropic 的"三重下注"（能力分数 + 云分发 + 自建电力）暴露了同一个脆弱点：三者都依赖持续融资。Nscale 的警告是这个链条上第一个具名裂口。

### AI Models：accelerating → **unchanged**（11-13，105 条信号）
- **核心证据**：Gemini 4 Hydrogen（同日进 Search AI Mode / Gemini app / 全部订阅层级）；Claude Fable 5.2 的 AA 65 分 + Mythos 5.2 上 Bedrock 与 Claude Platform on AWS；Nemotron 3.5 Super VL 上 SageMaker JumpStart。但**独立基准复现为零**。
- **我的判断**：发布密度极高、独立验证滞后，形成"评估期通胀"——所有人都能引用一个分数，没人能复现它。Fable 5.2 的 65 分是单一指数；Hydrogen 尚无 LMArena 数据。
- **对已有论点的影响**：用发布数量衡量进步速度会系统性高估能力曲线。P20261029-2（Gemini 4 Carbon 保持 AA 榜首）本周两次下调（0.48→0.40→0.33）正是这一通胀的直接体现：不是因为 Carbon 变差，而是因为同门新旗舰把它挤下去了。

### Developer Tools：fragmented → **unchanged**，但 126 条信号为全周最高
- **核心证据**：`anthropics/skills` 在 GitHub trending 连续第 10 天且仍在加速（velocity 6,169）；`google/elephant-goldfish-model` 单日 +5,560 星；高盛撤下 Claude Code；Claude Code settings 泄密；steganographic watermarking 争议。
- **我的判断**：开发者工具的竞争维度已经从"谁的补全更准"转到"谁的默认权限更可审计"。这是**采购驱动的转向，不是体验驱动的**。
- **对已有论点的影响**：本周 P20260712-1（企业因 token 成本迁离 Claude Code）被判为 needs_more_data 而非 strengthens，是正确处理——高盛撤离是第一例，但未披露归因，方向不明。

### Embodied AI / Robotics：fragmented → **accelerating**（11-13，18 条）
- **核心证据**：HF trending 的 EgoX（第一人称跨具身数据 + "embodiment dreaming" 对齐人类/真机/仿真演示）。但本周**没有**任何具名商业部署事件。
- **我的判断**：这是论文驱动的加速，不是订单驱动的加速。必须与 2026 年上半年那轮"人形机器人订单"叙事严格区分。
- **对已有论点的影响**：不构成对 Figure / Agility / Tesla Optimus 类部署预测的任何支持。相关预测（如 P20260617-6、P20260717-2）不应因本周信号上调。

## 4. 本周论文与研究前沿

本周论文信号全部来自 HF trending，**没有经过深度阅读**，这一点必须明说——它决定了本节结论的强度上限。

1. **EgoX**（just posted）— 第一人称跨具身操作策略，用 "embodiment dreaming" 对齐人类、真机与仿真演示。方向价值最高：它正面处理了具身智能最贵的问题（形态与传感差异导致的迁移成本）。**观察点**：是否开源数据管线与 dreaming 实现——若只有方法不给管线，实际推进有限。
2. **Back to Pixels**（just posted）— 论证 VAE latent 的时空压缩已成为高分辨率、可控、交互式视频生成的瓶颈，主张回到像素空间建模。这是一篇反共识的架构批评，若被采纳会改变主流视频生成的技术选择。
3. **The Value of Thinking**（just posted）— zero-or-T thinking，让单一混合决策模型自行选择直接作答或显式推理，压缩推理期 token 成本。与本周 P20260712-3（token 降价）和 P20261026-3（价格战）方向一致，是"成本压力 → 架构选择"这条链上的新证据。
4. **TurtLES**（just posted）— 14TB 三维湍流圆柱尾迹数据集。价值在基准而非方法：为 CFD 神经代理模型提供真实非定常流基准，弥补现有评测过于理想化的问题。
5. **Consensus Capture in Reference-Based UAV Video Stabilization**（just posted）— 揭示动态城市场景下参考帧稳像会因运动车辆失效。小而扎实的失败模式论文。

**惊喜**：EgoX 与 Back to Pixels 都在质疑各自子领域的默认假设，而非在默认假设内刷分。
**失望**：本周没有任何一篇论文能直接影响在册预测。Fable 5.2 的 AA 65 分依然是单一指数，没有 SWE-bench / Arena 的交叉验证；Gemini 4 Hydrogen 的独立排名为零。**研究前沿本周在动，但没有动到能被计分的地方。**

## 5. Startup / Unicorn 变化

- **Anthropic**：三重叙事同时推进——据报推进约 1.5 万亿美元估值 IPO（此前一份注册文件短暂上线后撤回，隐含最高 693 亿美元融资）、Dario Amodei 公开称算力采购是"最深的经营困境"、供应商 Nscale 警告需追加融资才能履约。**判断**：估值锚在能力叙事，履约风险锚在供应链融资，两周来第一次被同一个新闻周期摆在一起。这是本周最重要的未定价风险。
- **Fireworks AI**：Uber 披露黑客从其存储中窃取数千份司机驾照记录，为约两个月内第二次泄露。**判断**：推理层供应商正在成为"数据驻留"的实际持有者，但采购合同通常仍按"无状态 API"设计——这是合同模板与架构现实之间的系统性错配。
- **Nscale**：作为 Anthropic 算力供应商，公开警告需追加融资。**AI 基础设施二线供应商融资脆弱性的第一个具名样本**，值得独立跟踪。
- **Nebius**：$40B 计划中明确提到微软数据中心延期——卖方第一次把买方延期写进自己的融资叙事。这是一个范式变化：新云不再假装交付节奏由自己掌控。

**Watchlist 新增**：Nscale（融资履约压力测试）、Fireworks AI（推理层数据治理样本）。两者都不建议作为投资标的跟踪，而应作为**系统性风险的先行指标**跟踪。

## 6. Big Tech 变化

**Nvidia —— 三重集中度同时暴露。** 黄仁勋辞去总裁、CEO、董事职务，CFO Colette Kress 任临时 CEO，董事会据报接触 Arm CEO Rene Haas；员工"Bring Back THE Boss"请愿累计 1,600+ 条评论（HN 三帖 790/448/280 分，合计近 1,300 条评论）；特朗普在 Truth Social 提议 Tim Cook 接任。真正的战略问题不是谁接班，而是**单一供应商 + 单一强势创始人 + 单一管制通道**三者的同时失效。前两类风险历来可用降价、产能、游说对冲；第三类不能——它取决于政治上是否愿意继续给 Nvidia 例外，而走私指控与第三国执法显著抬高了这一例外的政治成本。此外，$48B / 229 家私营公司的投资组合从"生态护城河"变成了"治理议题"，VC 与创始人的预期已开始反映为更小的融资额度与更低的估值。

**Google —— 用一次发布解决能力与分发两个问题，同时主动让渡安全差异化。** Gemini 4 Hydrogen 同日进入 Search AI Mode、Gemini app 与全部 Google 订阅层级，配 Gemini Decisions API 与 Antigravity Orchestrator。这是"分发即护城河"的教科书动作。代价是：Ars Technica 明确指出它没有走 Carbon/Argon 式的慢速、以安全为先的发布流程，等于把"我们更谨慎"这一合规叙事资产主动让渡。叠加学校 Chromebook Gemini 试点引发的家长抗议与 "suicide coach" 诉讼，Google 正在用产品速度换监管摩擦——它赌的是监管滞后于分发。

**Microsoft —— capex 纪律与容量节奏是同一个事实的两种读法。** M365 近 24 小时全球中断（官方排除网络攻击与 AI 因素，归因坏更新 + 失效健康检查）是本季度最大云可靠性事故，医院、法院、学校、财报发布均受实质影响。叠加 Nebius 明确提到微软数据中心延期、微软据报重新评估 Nscale / IREN / Nebius 的新云交易。**这是未来两个季度最关键的分歧点**：同一组事实，读作"capex 纪律"利好利润率，读作"容量投放延迟"利空 Azure AI 增长。目前没有证据可以裁决，应保持双情景。

**OpenAI —— agentic commerce 的基础设施层卡位。** ChatGPT Wallet 面向美国 Pro 用户，覆盖 ChatGPT Work / Codex / Dots，支持 Amex / Chase / Mastercard / Visa 合格美国卡，机制为"用户批准 + 现有卡组织保护"。设计上非常聪明：审批权留给人、风控责任留给卡组织，避免自己成为支付责任主体。但这意味着**风险被外化给卡组织与商户**，而 chargeback 归责规则尚不存在——这是本轮真正的结构性变化，也是 P20261113-1 的赌注。

**Amazon / AWS —— 明确选择多模型中立聚合。** 一周内同时上架 ChatGPT Enterprise（Marketplace）、Claude Fable/Mythos 5.2（Bedrock）、Nemotron 3.5 Super VL（SageMaker JumpStart），并把 Amazon Quick 收编为 AWS Quick；同时扩容 Bedrock AgentCore 并出现 Natera SWARM 生产案例。这是与 Azure 相反的战略下注：不绑定单一伙伴，做中立分发层。

**Apple —— 本地模型的消费化试探。** 据报将推出便于在 Mac 上跑本地模型的 app（HN 550 分），与"本地模型采用"这一仍在加速的开发者趋势同频，但目前只有报道、无 API 或基准证据。相关预测 P20261112-3（2027-06-30 前发布一方 macOS 本地模型 app，p=0.65）应保持观察而非上调。

## 7. China Tech

本周中国科技的主线不在技术发布，而在**供应链与执法**：

- **走私估算与第三国执法具名化**：约 1.5GW 被禁加速器入华（SemiAnalysis 类单点估算）；马来西亚调查再出口；新加坡就 917 台 AI 服务器采购起诉一名高管。后者是本周最实质的变化——"第三国执法"第一次以具名案件形式出现，比任何政策声明都更有传导力，因为它把合规风险从行政成本转换为刑事成本。
- **对 Huawei Ascend 的份额加速**：黄仁勋辞职使 Nvidia 的对华许可游说失去最强支点。此前该游说依赖 CEO 级私人关系，临时管理层最理性的选择是"暂缓一切有争议动作"，这等于单方面让出窗口。
- **但需要克制**：本周**没有**任何证据表明中国云厂商的实际采购结构在本周发生突变。P20260515-1（Huawei Ascend 950 系列占 ByteDance/Alibaba/Tencent 新增 AI 加速器订单 >40%，horizon 2026-09-30，p=0.93）已过期未解析——**这条预测的状态比它的内容更值得关注**（见第 11 节）。
- **中国市场侧的产品信号缺失**：本周没有中国模型发布进入主线。HF trending 上 Qwen3.8-27B 转 decelerating 是唯一的技术侧信号，属生命周期正常衰减。

## 13. 错误类型分析
